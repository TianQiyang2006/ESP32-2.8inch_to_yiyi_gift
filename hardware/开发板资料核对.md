# ES3C28P 开发板资料核对

核对日期：2026-10-06。来源：[LCDWiki 2.8inch ESP32-S3 Display](https://www.lcdwiki.com/2.8inch_ESP32-S3_Display)，页面 revision 6127。

2026-10-06 后续更新：已通过 COM8 识别实板 ESP32-S3 revision v0.2，Flash 为 16MB，芯片工具报告内置 8MB PSRAM。原测试固件已保存；正式桌面工程见 `arduino/yiyi_desk/`，实板验证范围见 `LVGL验证记录.md`。电容触摸型号按用户提供的资料采用 ES3C28P；无触摸型号为 ES3N28P。

## 已从产品页确认

| 项目 | 文档参数 |
|---|---|
| CPU | ESP32-S3，双核 Xtensa LX7，最高 240MHz |
| 存储 | N16R8：16MB 外置 SPI Flash、8MB OPI PSRAM |
| 屏幕 | 2.8 英寸 IPS，240×320，ILI9341V，4-line SPI |
| 电容触摸 | FT6336G，I²C |
| 有效显示区域 | 43.20×57.60mm；横置约 57.60×43.20mm |
| 整板 | 50×86mm；电容触摸版本厚约 10.60mm |
| TF | MicroSD，SDIO 数据接口 |
| 联网 | 2.4GHz Wi-Fi，802.11 b/g/n |
| 音频 | 板载麦克风，I²S 音频接口，外接喇叭接口；资料列有 ES8311 和 FM8002E 芯片手册 |
| 供电 | USB-C；另有 3.7V 锂电池与充电接口，本项目用 USB |
| 小智 | 页面明确宣称支持小智 AI 语音聊天 |

产品页的蓝牙一栏写了 BR/EDR，不能据此认为 S3 有经典蓝牙：ESP32-S3 硬件支持 BLE，不支持经典蓝牙音箱所需的 BR/EDR。网页还存在接口说明拼接、串口收发标注等疑点；电气细节以原理图、对应版本源码和实物验证为准。

屏幕 SPI 与 TF SDIO 使用不同数据总线；不代表联合运行完全没有内存、DMA 或任务调度争用。外部 I²C 与触摸共享 GPIO15/16。

## 对当前设计的结论

- 8MB PSRAM 解决此前最大的文档未知项。时钟、天气、相册、留言、日历、倒计时、五页导航可继续设计。
- 静态罗小黑全屏背景可以作为默认视觉方案，纯白作为可选或加载失败后备。
- 一张 320×240 RGB565 全屏图像缓冲为 153600 字节，即 150KiB；两个缓冲约 300KiB，不包含字体、解码和音频占用。
- 适合少量帧角色动画、局部刷新和简单页面过渡；不承诺宣传图中的 100FPS 或全屏高帧率动画。
- 相册仍按需读取当前图片，避免把整卡图片载入 PSRAM。
- 汉字字体、实际显示对比度和触摸区大小需要按真实屏幕验证。
- 小智与定制 UI 的集成应基于对应板型源码；网页宣称支持，不代表现有成品固件可直接叠加全部功能。
- 已根据用户后续“继续完成”和“使用 LVGL”指示进入固件开发，先完成桌面功能；小智集成按用户确认留到后续。
