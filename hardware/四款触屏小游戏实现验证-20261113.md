# 四款触屏小游戏实现与验证 · 2026-11-13

按用户“打砖块，扫雷，见缝插针，记忆翻牌。全部一起做”要求，版本 `0.16.0-four-games` 一次加入四款原生小游戏。目标设备为现有 LCDWiki ES3C28P／ESP32-S3 N16R8，16MiB Flash、8MiB PSRAM，ILI9341 原生240×320面板以320×240横屏显示，FT6336G电容触摸，Arduino ESP32 2.0.17／LVGL 8.4。

本轮实现阶段完成规则、原生主机界面和固件验证，随后按用户“刷入”指令于2026-11-13把冻结的 `0.16.0-four-games` 部署到当前COM8设备，替换部署前的 `0.15.0-miner-plane`。下文分别记录实现阶段与新增部署阶段：实现汇总 `verification.json` 保留构建时无串口／无刷写的状态，部署结果另见 `deployment/deployment-verification.json`。设备串口模拟触摸已通过；实际手指体验尚待用户试玩。

工作区同时有另一个对话推进时钟改造，实时源码版本已进入 `0.17.0-dashboard-clocks`。为保留本轮四款游戏的独立构建与验证依据，`0.16.0-four-games` 的源码冻结在 `build/four-games-20261113/source/yiyi_desk/`，清单为同目录上层的 `source-snapshot.json`。下列界面与固件复现命令均使用这份0.16源码；工作区后续时钟修改不纳入本轮交付。

## 入口与操作

全部应用扩展为四页，每页最多六个入口。第三页第一行是跳一跳、羊了个羊、黄金矿工，第二行是飞机大战、打砖块、扫雷；第四页第一行是见缝插针、记忆翻牌。

| 游戏 | 触控操作 | 规则与进度 |
| --- | --- | --- |
| 打砖块 | 拖动场地相对移动挡板；轻点发球 | 三关，每关24砖、全局三条生命；后两关加入需击中两次的砖块。每次命中10分，击碎再加10分。 |
| 扫雷 | 点击翻格；按住500ms插旗，也可切换标记模式后点击插旗 | 10×6格、12雷，首点与周围3×3无雷；空白区域自动展开。翻开所有48个安全格获胜，满分680。 |
| 见缝插针 | 观察转盘空隙，轻点场地发射 | 三关分别需插入6／8／10针，第二关反向转动；针杆或针头相撞结束，每针1分。 |
| 记忆翻牌 | 依次点开两张牌，寻找相同图案 | 三关分别6／8／10对；错配展示750ms后盖回，暂停冻结该时段。每对100分，加步数奖励；三关完美累计3000分。 |

四款共用32px顶部返回、得分、最高分和暂停区，余下208px用于游戏。支持开始说明、暂停、继续、重新开始和返回；离开自动暂停，重入显示暂停层，当前App内部重建保持运行状态与进度。旧页面按住的触点必须先抬起才能在新页面操作，拖动到顶栏松手也不会误触返回。无底部方向按钮。

场景及图标使用LVGL矢量绘制，复用14／16px字体，不加入位图素材、额外字库或分区。四款规则引擎为固定容量C++11头文件，渲染与触控页面独立。打砖块5ms物理步长和连续碰撞检查；见缝插针在240ms飞行期间逐毫秒检测碰撞。两者页面20ms刷新，扫雷与记忆翻牌40ms刷新。

最高分分别保存在NVS `breakout/best`、`mines/best`、`pin/best`、`memory/best`。暂停、离开及结算时保存，读取未成功时保留原存档。应用编号追加为Breakout23、Mines24、Pin25、Memory26，`NavAppCount=27`，串口入口分别为 `app breakout`、`app mines`、`app pin`、`app memory`，`status` 返回各自状态与进度。新增游戏均持有场地触控、屏蔽游戏内全局切页手势，并免于空闲自动返回主页。

## 验证方法

规则回归使用真实生产引擎，包含正常游戏过程、边界、暂停与毫秒计数回绕。扫雷另以独立邻雷数和洪泛算法核对棋盘；记忆翻牌测试100个种子的全部三关和错配时钟。主机原生界面运行真实LVGL页面、字库与控件，注册pointer驱动，通过坐标按下、移动、松开模拟触控。

四个新runner验证自然得分、暂停恢复、重开、返回重入、拖动取消、触点跨页面隔离和反复开关弹层。扫雷通过真实生成盘的坐标完成胜负；见缝插针通过实际时机发射24针通关；记忆翻牌通过真实牌面的坐标完成三关3000分。打砖块使用真实发球与挡板拖动获得积分，关卡和胜负画面另有确定性场景；引擎测试使用正常挡板移动和发球完成三关。

每款分别执行“新局实际得分后暂停保存”和“新局实际得分后离开保存”，再启动全新进程读取同一独立存储目录，共八组持久化验证。所有中文字按实际页面字面量逐字核查两种字号。原六款游戏的页面截图与已部署0.15基线逐像素比较，前两页应用入口同样比较；原六款共14份引擎、页面和俄罗斯方块资源的SHA256与基线核对。

复现命令：

```powershell
python build/four-games-20261113/run_frozen_regression.py
python build/four-games-20261113/verify_frozen_ui.py
python build/four-games-20261113/verify_retained_games.py
powershell -ExecutionPolicy Bypass -File build/four-games-20261113/build_frozen.ps1
python build/four-games-20261113/collect_verification.py
```

主机原生构建使用本轮独立的 `build/four-games-20261113/host-lvgl` 对象缓存，上述原生验证顺序运行；固件构建读取冻结源码，构建目录为 `build/game-removal-arduino-build`，输出到本轮 `firmware/`。最终构建产物、源码副本比对、镜像校验、原生截图、八组存储目录及日志统一存于 `build/four-games-20261113/`，由 `verification.json` 汇总。四宫格原生预览为 `four-games-review.png`。
