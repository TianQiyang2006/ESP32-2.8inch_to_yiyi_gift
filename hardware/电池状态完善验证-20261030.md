# 电池状态完善验证（2026-10-30）

已将 `0.5.1-battery-status` 烧录到 COM8 的 LCDWiki ES3C28P / ESP32-S3 开发板，并通过独立 Flash 摘要校验、实板采样、页面检查及重启验证。该板已经装有电池，`batteryInstalled=true` 已持久保存。

## 实际读数与显示

- 连续 8 次采样，平滑电压为 4.151226～4.159843 V，估算电量 95～96%；每次均取得新的采样时间戳。
- 重启后读数为 4.154037 V、估算 95%，`voltageValid=true`。
- GPIO9 读取 R14/R15 各 200k 的二分之一电池电压。每 2 秒采样，丢弃首次转换，9 次取中位数，再低通平滑。
- 主页电池百分比、关于页电压和估算电量显示正常。外部供电设置开启时也显示实际估算电量，不固定为 100%，不显示未经确认的充电闪电。
- 模拟切换供电设置后读数有效、充电状态仍为未知；切回原设置后页面正常。这里验证的是软件设置切换，没有进行物理拔插 USB 或完整充放电测试，也没有进行万用表校准。

百分比由单节锂电池电压曲线估算，负载、温度和充电时电压抬升均会影响结果，估算 100% 不代表实际充满。

## 已实现的状态逻辑

- 电池供电且电压有效时，≤20% 进入低电量，≥25% 恢复；≤5% 进入严重低电量并以 500ms 节奏闪烁，≥8% 恢复。
- ADC 无效、未安装电池时显示“—”，电压和百分比遥测为 `null`，不使用旧电量或固定满电。
- 无效读数恢复、重新安装电池、修改供电设置时不沿用旧滤波结果。
- 关于页、手机配置页、串口 `power` / `status` 和 `GET /api/gift` 使用统一实时电池数据；手机刷新读数不会覆盖未保存的表单草稿。
- 串口 `power battery 0|1`、`power external 0|1` 可持久保存安装状态和供电设置，`power` 查询实时读数。

## 充电检测的硬件边界

本板的 TP4054 CHRG 与 USB VBUS 未连接 MCU，固件无法自动确认外部电源插拔、实际充电中或充电完成。因此保留 `chargingKnown=false`、`charging=null`、`chargingState=unknown`，显示“充电状态未知”，实际充电情况查看板上指示灯。自动检测需要补充对应硬件信号接线。

`externalPower` 来自手动设置，遥测明确标记 `externalPowerKnown=false`、`externalPowerSource=setting`。烧录前最新读取的设置为 `externalPower=false`；验证中分别测试 `true`、`false`，最终恢复烧录前的 `false`。该值不代表 MCU 检测到了 USB 已拔出，使用者应按实际供电方式在手机配置页调整。
