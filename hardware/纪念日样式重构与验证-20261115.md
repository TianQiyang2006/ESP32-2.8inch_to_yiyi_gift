# 纪念日样式重构与验证 · 2026-11-15

在现有 LCDWiki ESP32-S3 的“倒数日”应用内增加累计天数、可保存分类和五种可选样式。根据用户提供的六张手机截图，将交互整理为选择日子、选择分类、设置正数／倒数、选择样式与配色，并实时预览。

用户要求先看界面并确认后再烧录。界面预览、主机验证与固件构建完成后，用户于2026-11-15明确要求“刷入”，随后完成设备完整备份、app0烧录与运行核验。预览中的名称与日期均是测试示例，不作为用户的真实生日或相恋日期。

## 界面与交互

- 五种样式：简约（classic）、月桂（laurel）、笔触（ink）、爱心（heart）、点阵（dots）。设备端使用正式 LVGL 控件、渐变和矢量装饰，适配 320×240 横屏；手机端用 CSS/SVG 绘制对应预览。
- 普通／生日／相恋分类独立保存，名称和日期始终可自定义。缺少显式样式时，普通使用简约、生日使用月桂、相恋使用爱心。手动选择样式后优先使用保存的样式。
- 简约、月桂和笔触提供淡蓝、薄荷、奶油和深色；爱心提供红粉、橙金、紫色和蜜桃；点阵提供白色和深色。配色编号继续保存为0–3，以兼容已有数据。
- 卡片文字可选自动配色或自定义`#RRGGBB`颜色，手机提供取色器及HEX输入并即时预览。自定义颜色应用于名称、天数、状态、单位与日期文字，切换样式／背景／分类时保留；恢复自动会移除自定义字段，旧记录继续自动配色。导航与设置按钮不受影响。
- 正数使用今天减开始日期：开始当天0天，次日1天；未来开始日期显示距离开始的天数。倒数沿用目标日期减今天的规则。计时日不可每年重复。
- 生日可每年重复；2月29日在非闰年按2月28日处理。按北京时间自然日计算，午夜刷新；未校时显示等待状态。
- 列表每页三条，支持点击详情、返回、翻页与手机管理入口；最多20条。手机可选择已有记录、新增、编辑和删除，保存期间的草稿保护与原子持久化继续生效。

## 数据接口

`GET /api/gift` 返回 `countdownDays.items`。通过 `POST /api/countdown-days` 保存单条记录：

```json
{
  "action": "upsert",
  "item": {
    "id": 0,
    "name": "我们相恋了",
    "date": "2026-01-01",
    "yearly": false,
    "color": 0,
    "mode": "countup",
    "category": "love",
    "style": "heart",
    "textColor": "#6B2760"
  }
}
```

`id: 0`新增，已有正整数编号编辑；删除仍为 `{"action":"remove","id":1}`。示例日期只用于说明。

原有五字段记录保持兼容。`mode`、`category`、`style`和`textColor`分别可选，允许全部有无组合，最多九字段；缺少模式按倒数处理、缺少分类按普通处理、缺少样式按分类选择默认、缺少文字色按主题自动配色。字段类型、未知值、嵌入空字符及多余字段均严格检查；文字颜色仅接受七字符`#RRGGBB`，十六进制字母大小写均可。
