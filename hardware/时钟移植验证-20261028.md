# Pixel Clock 与白色翻页时钟验证（2026-10-28）

已完成编译、COM8 实板烧录和验证。按最新要求取消 Pocket Pet，没有添加宠物应用或应用页入口。

## 改动

- “时钟模式”中的“蓝色像素”替换为 Pixel Clock，设置值仍为 `matrix`，兼容已有配置。
- 适配原项目的 19×9 方块与 3×5 时分数字，保留闪烁冒号、点击掉落方块和自动小蛇。点击特效最多同时存在 6 个，小蛇移动有边界检查和步数上限。
- 日期、时间与天气共用桌面的数据源；没有导入原项目的屏幕驱动、网络任务或固定时区时钟。
- 白色翻页改为沿中线垂直压缩旧数字上半片，再展开新数字下半片，数字与翻板一起变形，并随角度变暗。初次进入直接显示当前时间，相同目标的重复刷新不会中断动画。
- 两个钟面支持顶部返回按钮。页面删除时取消计时器、释放缓冲，切换到缓存首页时停止动画。
- 翻页栅格缓存与运动半片使用 PSRAM，合计 149,408 字节；内存申请失败时显示静态数字。
- Pixel Clock 的 MIT 许可证随源码保留于 `arduino/yiyi_desk/src/pages/PIXEL_CLOCK_LICENSE.txt`。

## 板子与空间

板子为 LCDWiki ES3C28P / ESP32-S3，16 MiB Flash、8 MiB PSRAM，ILI9341，横屏 320×240，FT6336G 触摸。桌面仍使用 Arduino ESP32 2.0.17、LVGL 8.4。

| 项目 | 结果 |
|---|---:|
| 桌面 app0 分区 | 9,961,472 字节（9.5 MiB） |
| 最终 `.bin` | 5,790,560 字节（约 5.52 MiB） |
| 相比原版增加 | 3,168 字节 |
| 桌面分区剩余 | 4,170,912 字节（约 3.98 MiB） |
| Pixel Clock 可用内部堆 | 124,020 字节 |
| Pixel Clock 可用 PSRAM | 7,755,627 字节 |
| 白色翻页可用内部堆 | 161,444 字节 |
| 白色翻页可用 PSRAM | 7,606,203 字节 |

应用页预览使用直接绘制，避免为缩略图创建 171 个装饰控件。固件编译输出静态 RAM 76,260 字节。实际占用还会随联网状态与当前页面变化。

## 验证结果

原生 LVGL 离屏测试通过：

- 预设保存失败处理，以及继续沿用 `matrix` 设置值。
- Pixel Clock 秒数与冒号更新、自动小蛇、点击特效数量上限及清理。
- `09:59:59 → 10:00:00` 六位同时翻页，折叠、中线、展开和结束帧。
- 动画完成后的画面与直接进入目标时间的画面逐像素一致。
- 动画期间重复刷新、时间跳变、跨午夜、未校时与恢复校时。
- 30 次反复创建、动画期间退出和删除，计时器数量恢复基准。
- 山水钟面继续显示正确时间。既有主页面的离屏渲染也通过。

COM8 实板验证通过：

- 应用页、钟面选择、两个钟面和顶部返回按钮。
- 自动小蛇截图检测到 588 个绿色像素，翻页前后截图有 2,414 个像素变化。
- 10 次交替进入 Pixel Clock / 白色翻页，再返回应用页，确认每次实际进入目标钟面。
- 预热后，同一应用页的可用堆范围为 159,668～159,720 字节；PSRAM 每次恢复至 7,755,627 字节，没有持续下降。
- 七个主页面、天气和设置页面可进入。
- `logic / touch / screens / uiExport / widgets / text / lunar` 全部 PASS，`SELFTEST PASS`。

实板检查通过 USB 模拟触摸与 CRC 校验的 LVGL 帧缓冲截图完成。没有用摄像机检查实体面板颜色，也没有用手指重新检查触摸；小智 app1 没有在本轮启动。
