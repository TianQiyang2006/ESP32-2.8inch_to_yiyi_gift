# 像素时钟烧录与实板检查

2026-10-11，ESP32-S3，COM8。已烧录青蓝发光方块点阵钟面：大号 HH:MM，下方小号 SS。固件同时包含中文天气城市输入、UApi 天气、手机留言编辑和免网页登录配置页。下文记录首次桌面更新；随后已按用户要求完成桌面、小智及资源的完整烧录，最新记录见 `hardware/全部固件烧录验证.md`。

## 烧录范围

使用 esptool 4.11.0 的 ROM 模式（`--no-stub`）仅写入 0x10000 起始的桌面固件。工具补齐后的写入长度为 7,256,064 字节，仍在 app0 的 0x780000 容量之内。写入完成，返回 `Hash of data verified`，随后重启。

引导程序、分区表、NVS、OTA 选择、官方小智 app1、资源和 LittleFS 在本轮写入范围之外；没有全片擦除或格式化存储。

## 实板结果

- 设备启动后正常响应，16 MiB Flash、约 8 MiB PSRAM 正常。
- 自检中 logic、touch、screens、uiExport、messages、widgets、text 全部 PASS。
- 通过串口 UI 命令打开时钟选择页，点选第二张卡片。实际渲染画面为黑底青蓝点阵时分和小号秒数。
- 相隔两秒以上取得两张经过 CRC 校验的设备帧截图；秒数区域像素变化，运行时间持续增加，没有检查期间重启。
- `touchCalibrated=true`；触摸模式、亮度 100、音量 49、BGR 与反色参数均与烧录前一致。
- 最终停留在像素钟面（App::Clock = 12）。

设备帧截图为 `build/device-pixel-clock.png` 和 `build/device-pixel-clock-next-second.png`。设备报告为 `build/device-pixel-clock-verification.json`；编译、备份和烧录日志分别为 `build/pixel-clock-final-compile.log`、`build/pixel-clock-backup.log`、`build/pixel-clock-upload.log`。

设备目前 `wifi=false`、`timeValid=true`，显示保留的 RTC 时间；本轮尚未联网校时或验证实板天气请求。连接可上网的 2.4 GHz Wi-Fi 后自动校时和请求天气。热点自动弹页尚需实体手机验收。上述点击来自串口模拟，检查验证设备渲染及逻辑，不替代物理触摸或屏幕颜色的实物验收。

主机 LVGL 的逐秒、跨分钟及跨午夜检查通过；像素钟 JS 检查 5/5 通过。
