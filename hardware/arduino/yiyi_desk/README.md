# 给依依的小黑桌面 · LVGL 固件

LCDWiki ES3C28P，ESP32-S3 N16R8，原生 240×320 IPS 面板，ILI9341 与 FT6336G 电容触摸；七页以 320×240 横屏显示。七页按已经确认的 HTML 设计移植，采用原始插画；日期、天气、日记、留言和倒计时均保留为独立控件。

## 页面与交互

七页依次为主页、天气、放假倒计时、每日名言与诗句、心情与日常、课程表、全部应用。左右滑动或点击底部圆点切页。全部应用每页最多6个入口：第一页为时钟模式、课程表、天气、小智AI、日历、设置；第二页为闹钟、番茄时钟、音乐、游戏、倒计时和倒数日；第三页为在线 FM。10款游戏统一从“游戏”进入：列表第一页为俄罗斯方块、贪吃蛇、跳一跳、羊了个羊、黄金矿工、飞机大战；第二页为打砖块、扫雷、见缝插针、记忆翻牌。退出具体游戏回到列表并保留列表分页，再返回回到全部应用。当前源码已移除原15款游戏厅，现有10款游戏保留各自玩法与存档；相册没有页面或应用入口。

`0.2.3-voice-smooth` 为七页、应用和详情入口加入缓动渐变揭示（2026-10-19 起为 180～200ms，过渡带宽已收窄）。先在 PSRAM 完整生成目标画面，再经窄条区域传输到面板；动画期间暂时屏蔽点击，按住屏幕须松手后才能操作新页。实时图标、样式和显隐仅在变化时更新，避免静态页面反复重绘；界面标签按秒刷新，亮度/音量拖动与木鱼、饮水等操作会立即刷新。

- 主页引用天气页的共享地区和数据，没有固定默认城市。NTP 北京时间同时驱动星期、月历、周历和倒计时。未校时显示等待提示，日记不写入猜测的日期。左下角 Wi-Fi 图标在未联网时变暗并叠加红色叉号，联网后恢复正常，文字保持“Wi-Fi”。
- 天气使用 `https://uapis.cn/api/v1/misc/weather`，按中文城市名称查询，开启 `extended=true` 和 `forecast=true`。显示当前状况、体感、温度范围、湿度、风向风力、日出日落、气压、紫外线、能见度、接口空气质量指数及类别和最多七天预报。10 分钟更新，失败保留缓存，不可用字段显示 `--`；换城市后清除旧地区天气并更新。
- 放假目标星期可在手机选择，当天显示当天文字，否则计算到下一个目标星期的自然日；元旦和春节分别计算。节日卡片可打开对应日历。
- 第四页一言使用 `https://uapis.cn/api/v1/saying`（根字段 `text`，无作者）；诗词使用 `https://poetry.palemoky.com/api/poems/random?lang=zh-Hans`（全文及元数据）。支持缓存、自定义内容和点击全文，旧一言缓存自动迁移，失败保留。示例内容明确标为“示例”。
- 第五页支持今日及本周已经过去日期的心情日记、LVGL 拼音输入，未来日期不可记录。200/500 ml 饮水可在详情撤销上次；木鱼计数可撤销一次，声音跟随音量。
- 三张倾斜便签可进入详情。标题、日期、可滚动正文、落款分开排版，手机修改文字时原地更新并保留阅读位置。
- 钟面为时光动画、Pixel Clock 和白色翻页。时光动画保留 `landscape` 设置值，上方固定显示实时时分秒和日期，下方保留 `Ui设计图片/时钟功能预设/1` 原第1、2、5段共三个 GIF（0.10.3移除原第3、4段）；默认停在第一帧，单击播放一轮后回到静止帧，320ms 内双击切换下一个 GIF，三个循环切换。GIF 等比例缩放，解码画布及 LZW 表放在 PSRAM。Pixel Clock 保留 `matrix` 设置值，使用 19×9 方块、3×5 时分数字、闪烁冒号，保留点击掉落方块与自动小蛇，下方显示日期、秒数和天气。白色翻页使用沿中线压缩、展开的上下半片，数字与翻板同步变形，初次进入直接显示当前时间。三个钟面都不显示顶部标题与返回箭头，通过屏幕左边缘向右滑返回；未校时时显示横杠，页面销毁时释放动画缓冲和计时器。
- 设置可立即调整亮度 10～100% 和音量 0～100%，0 静音；停止调节后合并保存。
- 第六页为课程表：周一到周日 7 天、1–10 节，色块显示课程名；顶部 `‹ ›` 切周，点色块看教师、教室、周次与节次时间。单双周、短周课程按所选周过滤，第 1–2 周的周六日课程也保留。
- `0.7.0-approved-focus` 将闹钟和番茄时钟定稿接入正式固件。闹钟支持5组独立设置、分钟滚轮、星期重复、3种本地铃声和试听、独立音量、贪睡、渐强、删除确认；提醒设置页上滑可进入更多设置。后台任务每100ms调度，任何桌面页面都能显示响铃层。配置及触发标识采用双槽CRC存储，保存成功才启用；重新通电读取配置，恢复有效北京时间后继续调度。

## 倒计时与闹钟删除（0.10.0）

倒计时位于全部应用第二页，采用时／分／秒滚轮，范围为1秒至23:59:59，默认15分钟。内置刷牙2分钟、蒸蛋10分钟、面膜15分钟、午睡30分钟；点常用项填入时长，再点「开始」。常用列表可上下滚动；「添加」保存当前时长和名称，最多8项；长按常用项可改名或删除。名称支持屏幕英文键盘，并提供「学习／运动／提醒」中文快捷名称。

倒计时支持开始、暂停、从剩余时间继续、重置确认和结束后再来一次。返回桌面后继续计时；到时在任意桌面页面显示提醒层，可停止提醒，最长提醒60秒。使用64位单调时钟，不依赖Wi-Fi或NTP。提示音复用闹钟的「经典滴滴／温柔钟声／渐快提醒」，可试听、独立设置0～100%音量，默认20%，0为静音。闹钟响铃优先，停止闹钟后，仍在提醒时间内的倒计时恢复提示音；停止倒计时不会停止番茄提示音。

常用项、最近一次启动或保存的时长及提示音设置使用独立NVS命名空间、双槽CRC记录保存；保存失败时保留旧值。重启后保留这些设置，进行中的倒计时需重新开始。

闹钟列表每条卡片新增可直接点击的「删除」，确认后删除该条并取消其贪睡、待响与当前响铃状态；取消返回原列表。原有「更多设置 → 删除闹钟」入口保留。删除保存失败时保留原闹钟。

## 电池与外置充电模块

本机已安装德力普单节 18650，标称 3.7 V、12775 mWh，折算约 3453 mAh。默认安装状态为开启；既有保存设置继续保留。按用户最终要求，日常充电仅通过外置充电模块完成。固件不控制外置模块的充电电流、恒流恒压阶段或充满终止。

BAT ADC 为 GPIO9，R14/R15 各 200k，读取 BAT+/2。每 2 秒丢弃首次转换后取 9 次读数中位数，再做电压平滑。所有页面持续采样，接电时也显示实际估算电量；关于页和手机页显示电压，手机页另显示剩余 mAh 估算。百分比和剩余容量均按单节锂电池电压曲线估算，受负载、温度及充电时电压抬升影响，不是库仑计结果，不预测剩余使用或充电时间，也不使用商品图的“7 小时左右”作为固件定时终止条件。100% 不代表充电完成。

电量 ≤20% 弹出“电量不足，请通过外置充电模块充电”，点“知道了”关闭；本次低电过程不反复弹出。恢复到 ≥25% 后重新允许下次低电提醒。降到 ≤5% 再提醒一次严重低电，并保留电池图标闪烁；恢复到 ≥8% 后解除严重低电。同样的规则用于音乐/小智应用，使用各自 LVGL 弹窗。提醒不被手动“外接供电”设置屏蔽，不修改亮度、音量或功能，不自动休眠、不关机、不重启、不要求按 RESET，也没有启动电压门槛。

ADC 超出 2.50～4.45 V 时电量显示“—”，遥测电压和百分比为 `null`，弹窗提示检查连接，不使用旧电量或固定满电。连续 3 次有效采样达到 4.25 V、持续至少 4 秒时显示电压偏高提醒，回落到 ≤4.15 V 后解除；这是异常电压提示，不能切断充电。移除电池、无效读数恢复和切换供电设置都会清除旧滤波影响。

本板 TP4054 的 CHRG、USB VBUS、电池电流和电芯温度没有连接至 MCU，因此固件不能检测充电中/充满，也不能控制开充/停充、电流、过流或短路切断。`chargingKnown=false`、`charging=null` 如实表达没有检测信号，不能用电压上升冒充充电中。外部供电设置仅记录用户指定方式，不参与电池告警判定。

外置模块的硬件保护只有在相应电流路径经过其保护开关时才覆盖该路径。用户描述的开发板直接接电芯线路不受外置板另一支路的开关控制；要覆盖开发板供电，应把开发板电池口接到模块的受保护输出，电芯接模块电池端，具体端子以该模块电路为准。板载 TP4054 没有 MCU 关断脚，软件无法使它在开发板 USB 带 5 V 时停止充电；落实“仅外置模块充电”需要在供电/接线中避免给板载充电器供电，或由硬件断开其充电支路。

串口 `power`、`status` 的 `battery` 和 `GET /api/gift` 提供实时电池数据，包括电池规格、估算剩余容量、告警、`protection.mode=notify_only`、`automaticSleep=false` 和检测/控制能力。没有“接法待核实”字段或相关配置。串口 `power battery 0|1`、`power external 0|1` 持久保存安装与供电方式；遥测不写入配置，手机刷新读数时保留表单草稿。

回归检查：`python hardware/scripts/test_power_status.py`、`python hardware/scripts/test_native_lvgl.py --pages`、`node --test tools/design-review/check-mobile-config.cjs`。音乐构建脚本从桌面复制同一份 `battery_policy.h`，避免两套阈值漂移。
