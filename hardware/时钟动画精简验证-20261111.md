# 时钟样式一动画精简 · 2026-11-11

版本：`0.10.3-clock-trim`。按用户要求删除原第3、4段动画，保留原第1、2、5段，已编译并写入 COM8。

## 实现

- 从生产资源目录移除 `clock_gif_2.c/.gif` 和 `clock_gif_3.c/.gif`，同步删除头文件声明和清单记录。原始输入素材及修改前快照仍保留供恢复。
- 时光动画的双击切换顺序为原第1 → 第2 → 第5 → 第1段，数量由实际素材数组推导。单击播放一次、结束恢复首帧、固定时间和日期保留。
- 素材生成器只生成原第1、2、5段，并在清单记录对应符号。重新生成的八个生产资源文件与保留版本逐字节相同，避免以后重生成时重新加入被移除动画。
- 主机及设备验证脚本同步为三段动画；主机逐帧对照依照清单读取对应GIF文件。
