# 小智字体显示修复验证（2026-11-11）

## 修复

当前运行的是 `xiaozhi-esp32-2.5.3-dev-grokbot` 中的
`yiyi-es3c28p-grokbot` 板型，屏幕为 320×240 彩色 LCD。
原状态栏、对话字幕及状态图标采用 14px/1bpp 字体；该文字配置是为单色小屏
准备的 ExtraLight 200 字重，细笔画缺少灰阶过渡。

- 本板文字与状态图标改用常规字重 16px/4bpp，支持 16 级灰度抗锯齿。
- 将完整 common CBIN 字库嵌入 app1，以保留全部 28 组动画并满足固定资源分区容量。
  字形位图直接从应用 Flash 映射读取，不将整份字库复制进 RAM。
- 状态栏、字幕容器按实际字体行高预留空间，清除状态栏原有上下内边距。
  common 字体实际行高 25px；字幕栏 29px，标签位于 y=213～237，容器内容区
  y=211～239，保留 308px 宽和单行循环滚动。
- 本板拒绝旧资源包中的 1bpp 字体，支持只更新 app1。缺字推送保守上报
  16px/4bpp basic 字集；实际内嵌 common 字集覆盖其超集。
- 增加 USB 字体检查及文字注入命令，以及可重复运行的实板验证脚本
  `hardware/scripts/check_grokbot_fonts.py`。
