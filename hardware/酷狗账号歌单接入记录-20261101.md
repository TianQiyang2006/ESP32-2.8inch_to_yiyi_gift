# 酷狗账号歌单接入记录 · 2026-11-01

现存酷狗扫码登录凭据可用，真实账号“我喜欢”接口返回131首歌曲。本次没有修改酷狗账号收藏，也没有改动设备固件。

## 接入结果

- 酷狗适配器新增两个只读路由：`/user/playlist`、`/playlist/track/all/new`。
- 新增MCP工具 `yiyi_kugou_playlists`、`yiyi_kugou_playlist_import`。小智云已连接并完成初始化，工具数为22。
- 已按用户要求完成131／131首全量导入，保存到本地命名歌单“酷狗我喜欢”；131首均通过播放接口、文件时长和解码校验，最终失败0首。初次接入阶段仅导入5首，后续全量任务复用了这5首缓存。
- 导入按酷狗歌单原始hash、专辑ID及歌曲ID取音源，避免旧收藏因搜索结果缺少原版本而失败。既有点歌流程继续复用相同音源准备逻辑。
- 导入只追加并按歌曲ID去重；失败页不会清空原有歌单，返回失败原因和下一页。每批最多5首，分页期间必须保持批大小不变。
- 本地歌单容量由100首提高到200首；媒体缓存仍限制300MB，并在写入前检查新增音频是否超过上限。

## 验证

- 本机及VPS的23项单元及HTTP回归测试通过。
- 真实MCP SDK stdio会话发现22个工具；实际调用歌单导入返回首批5首成功、0首失败、`next_page=2`。
- 5首歌曲均通过固件查询接口解析、MP3 HEAD、Range分段读取和FFmpeg片段解码检查；48kbps音频文件大小与歌单标注时长一致，未观察到试听片段长度。
- 检查时实体设备离线，因此本次未发起扬声器播放，不能将服务器解码验证写成设备听感确认。先前语音回复卡顿问题本次没有修改。
- 部署仅重启新增的`yiyi-kugou`和`yiyi-mcp`相关服务；后续Python补丁仅重启`yiyi-mcp`。没有重启其他VPS服务或音乐网关。

## 使用

设备联网并进入音乐小智应用后，先唤醒，再说“播放酷狗我喜欢歌单”或“随机播放酷狗我喜欢歌单”，播放当前已导入的部分。“下一首”“暂停音乐”“继续播放”仍使用既有播放控制。

歌单现有131首，直接说“播放酷狗我喜欢歌单”即可使用。以后添加新收藏时可重新逐页导入：从`yiyi_kugou_playlist_import(page=1,batch_size=5)`开始，保持批大小不变，按返回的`next_page`继续，直到`has_more=false`；已有歌曲自动复用和去重。本次是手动导入快照，酷狗App里的后续增删不会实时同步。

账号的单曲权限、安全验证、试听和20分钟时长限制仍适用；工具会报告无法准备的曲目。
