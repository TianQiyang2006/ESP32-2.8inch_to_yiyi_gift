# 游戏厅定稿实现与验证

日期：2026-11-12。版本：`0.11.0-arcade`。

用户审阅320×240布局预览后确认“可以，我很满意”。本版已按该布局完成生产LVGL代码、完整固件和主机验证，**尚未烧录开发板，实物触控与声音未验收**。

## 游戏与入口

全部应用第二页新增“游戏厅”，三页游戏列表共有15款新增游戏：扫雷、2048、五子棋、贪吃蛇、推箱子、数字华容道、记忆翻牌、打砖块、数独、黑白棋、解压泡泡、连连看、迷宫、井字棋、接水果。原有俄罗斯方块保持独立入口，共16款。

游戏厅和各款规则均可离线使用。游戏规则为本项目实现，不依赖网页或联网小游戏服务。

| 打砖块、接水果 | 320×176场地，底部320×32相对拖动区；按下不跳位，拖出轨道仍跟踪，松手停止。打砖块轻点轨道发球。 |

| 记忆翻牌、连连看、泡泡 | 采用横向展开的大卡片或大触区，常驻信息压到顶栏。连连看保留外绕连线路径。 |
| 迷宫 | 320×200地图、16×10格；滑动或点角色相邻格走一步。 |

暂停菜单统一提供继续、游戏选项、重开、说明、返回列表。重开必须确认；华容道切换规格也须确认，取消或离开不会泄漏未确认的规格。游戏内滑动由游戏独占，通过显式返回按钮导航；返回先暂停。

暂停、选项和说明页停止游戏进度。记忆翻牌使用只在运行时推进的时钟，暂停不会消耗未匹配牌750ms的剩余展示时间。查看结算棋盘时禁止继续操作。

## 最终容量

| 项目 | 数值 |
|---|---:|
| 桌面分区 | 8,912,896 B（8.5 MiB） |
| 完整应用镜像 | **8,911,824 B** |
| 镜像占分区比例 | **99.98797248%** |
| 分区剩余 | **1,072 B** |
| 编译器程序占用统计 | 8,911,457 B（不含全部镜像封装开销） |
| 静态RAM | 111,900 B |
| 编译器报告的静态RAM余量 | 215,780 B |
| 内置推箱子 | **12,611关**，每条记录95 B，共1,198,045 B |

容量按`.bin`实际长度核算。余量为镜像封装与对齐留下的小幅空间；没有加入无用途的填充数据。NVS、小智4MiB、资源2.5MiB及LittleFS等分区沿用现有布局。

最初资源版超过分区，因此对新增资源做了以下取舍：

- 把仅由游戏引用的完整8/10/12px常规字体，提取为每套404个实际所需字符的子集。直接复制旧字形记录，保留字形指标、行高、基线与回退，不修改其他应用的字体。
- 15张320×136封面改为INDEX8，配套94×40原尺寸RGB565缩略图。封面及缩略图共780,960 B，较原RGB565封面减少524,640 B；大厅无须缩放索引图，也无须分配整张解码画布。
- 优化后1024关镜像为7,811,056 B，剩余空间用于增加11,587个实际可玩的推箱子关卡。扩充后的前1024关数据逐行哈希不变。

关卡用固定种子、反向拉箱生成；每关都重放导出的正向解法。地图、箱子、起点组合去重；扩展库不会改变既有前缀。

## 存档

- 成绩：独立`arcade`命名空间，交替`best0/best1`记录、序号及校验；短写或失败保留旧有效记录。
- 推箱子：离开时保存最后选择的关卡。
- 数独：独立`arc_sudoku`命名空间，`s0/s1`各363 B，含版本、序号和CRC32；写入后读回校验。离开与完成时保存盘面、笔记等状态，失败有界面提示并重试；可跨重启恢复。
- 其他本局棋盘在同次运行中保留，重新上电后新开一局。

## 验证证据

`build/arcade-20261112/verification.json` 为最终源码的主机验证；`firmware-verification.json` 为镜像、分区和构建副本核对。

- 最终ESP32 Arduino 2.0.17-cn、LVGL8.4、GNU C++11整包编译通过。镜像校验和及验证哈希均由esptool检查为有效。
- 416个C/C++/头文件与实际构建副本核对一致，仅移除Arduino CLI自动插入的第一行`#line`指令后比较余下全部字节；最终native报告的源码SHA256与工作区一致。
- 15款游戏均通过真实GiftUI应用入口、游戏卡片与开始按钮进入，生成62张真实LVGL截图。
- 781个标签、2280个字形、886个控件、415项布局断言全部通过，无缺字、裁切或越界。
- 全部15款暂停冻结、选项与说明往返、状态保持、重开取消/确认、胜局棋盘冻结及45次反复切换与退出重入通过。
- 四套规则测试通过：12,611关推箱子全解及完整撤销；200个滑块可解性样例；3235项棋类检查；100个迷宫连通与对称检查；10,000组连续水果落点检查；扫雷、2048、记忆、数独唯一性及连连看独立路径对照等。
- 8个成绩跨进程读写与故障恢复场景、2个数独跨进程保存恢复场景通过。数独单测另覆盖短写、CRC损坏及有效旧槽恢复。
- 字体子集的103,475个解码像素与原字体完全相同。资源优化前后61张截图中57张逐像素一致，4张预期变化限于大厅/介绍页封面；所有游戏和菜单画面一致。独立证据保存在`after-resource-opt-1024/`。
- `run_host_regression.py` 全部通过，覆盖导航、手势、既有俄罗斯方块规则、天气、触控驱动、音频与音乐存储等。

常用复验命令：

```powershell

```
