# 手机配置与 UApi 天气验证

2026-10-11。本轮实现手机输入中文城市、更新天气 API、编辑留言、连接设备热点后进入免登录配置页。保留七页桌面的现有布局与样式；已将含秒数的桌面固件、小智 2.5.0 和官方资源完整烧录到 COM8。2026-10-21 按用户要求保留热点自动弹页，删除配置页中失效的 Wi-Fi 扫描功能，并移除全部 SD 卡相关代码。

## 使用方式

1. 在开发板“设置 → 连接手机”查看热点名、Wi-Fi 密码与连接热点的二维码。
2. 手机扫码或手动连接该热点。设备提供通配 DNS 和 Android、iOS、Windows 网络探测重定向，自动打开配置页；无需网页登录，热点连接仍使用 Wi-Fi 密码。
3. 若手机没有自动弹页，请手动打开 `http://192.168.4.1/`。配置页不再提供 Wi-Fi 扫描按钮；请优先在设备屏幕“设置 → Wi-Fi 配网”搜索，或在配置页手动填写网络名和密码。
4. 在“天气城市”直接输入中文城市名称并保存，例如杭州、北京、昆明。开发板连接可上网的 2.4 GHz Wi-Fi 后更新；无需经纬度或手机定位授权。
5. 在“想对你说”编辑标题、正文、落款，点击“保存留言”，内容同步到桌面并保存在设备。留言编辑不要求设备已接入互联网。

## 实现与验证

- 天气请求：`https://uapis.cn/api/v1/misc/weather?city=<UTF-8编码城市>&extended=true&forecast=true&lang=zh`。读取原始天气描述、风向风力、扩展气象字段、接口空气质量类别和最多七天预报。
- `/api/location` 接收城市名称并保存到 NVS。旧城市的在途天气请求不会覆盖新城市；同城刷新失败保留缓存，缺失字段显示占位，零值正常显示。
- `/api/gift` 读取与保存共享设置及留言。配置页没有 Basic Auth 登录；HTML、样式和脚本自包含。
- 手机配置轮询保护未保存的城市和留言草稿；保存期间继续输入的新草稿保留，旧轮询不能覆盖新保存的内容。
- 真实 UApi 杭州请求已成功。另用隔离存储执行完整 HTTP 城市查询、设备共享读取、中文留言保存/回读及持久化验证，结果在 `build/mobile-config-http-live.json`；未覆盖正在使用的手机配对配置。
