# ES3C28P 小智 / GrokBot 移植记录

目标：在现有 ESP32-S3 N16R8 开发板上运行 `xiaozhi-esp32-2.5.3-dev-grokbot` 的小智状态联动与 GrokBot 动画，同时保留 app0 桌面及其应用。旧音乐小智的点歌、歌词、频谱扩展不在此次移植范围。

## 硬件与分区

实板为 LCDWiki ES3C28P：ILI9341 IPS 320×240 横屏、FT6336G 触摸、ES8311 音频、16 MiB Flash、8 MiB OPI PSRAM。板型独立为 `yiyi-es3c28p-grokbot`。

| 分区 | 地址 | 容量 | 本次处理 |
| --- | --- | --- | --- |
| nvs | 0x009000 | 0x005000 | 不直接烧写；应用保留共享配置 |
| otadata | 0x00e000 | 0x002000 | 不烧写；应用切换时正常更新 |
| app0 | 0x010000 | 0x780000 | 桌面仅增加 2.5.3 识别及离线进入 |
| app1 | 0x790000 | 0x500000 | 新版小智 / GrokBot |
| assets | 0xc90000 | 0x280000 | 原 model 同地址同容量，改为新项目资源包 |
| spiffs | 0xf10000 | 0x0f0000 | 桌面 LittleFS 保留 |

启动程序保持不变。不能使用旧工程的 9.5/3 MiB 分区表，也不能将新版默认合并镜像整片烧入。

## 代码与构建

- 新板实现位于 `xiaozhi-esp32-2.5.3-dev-grokbot/main/boards/yiyi-es3c28p-grokbot/`。
- 保留 28 组动画，重采样为 200×200，目标 20 FPS，20 行内部 DMA 缓冲；无 TE 引脚。
- 复用桌面 Wi-Fi、触摸校准、亮度与音量；退出按钮设置 app0 并重启。
- ES8311 输入/输出为 24 kHz，上行由 AudioService 重采样为 16 kHz；PA 低有效。
- 禁止在线固件与资源替换，避免双应用与本地资源被覆盖；共享 NVS 初始化失败时停止，不自动擦除。
- 使用 ESP-IDF 6.0.1；Windows 构建通过 ASCII 缓存及 Ninja response file 处理路径和命令行长度。

完整首次构建：

```powershell
& .\hardware\scripts\build_grokbot_firmware.ps1
```

已完成板型配置后的增量构建（脚本先校验配置）：

```powershell
& .\hardware\scripts\build_grokbot_firmware.ps1 -Incremental
```

安装脚本 `hardware/scripts/install_grokbot.py` 默认仅检查备份、分区、应用描述符、保护配置、资源校验和与容量，输出安装计划。`--flash` 才实际写入，并独立 verify_flash。`--restore --flash` 从已校验备份恢复分区表、OTA 元数据、两个应用和原模型，不回写当前共享 NVS / 桌面 LittleFS。

烧录应使用 IDF 6 Python 环境。设备截图与诊断脚本使用已安装 Pillow / pyserial 的系统 Python。
