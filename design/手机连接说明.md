# 手机连接与设置

## 预览连接

电脑运行 `./design/start_phone_service.ps1`；缺少依赖时运行 `python -m pip install -r design/requirements-phone.txt`。预览仍为 [设计工作台](http://127.0.0.1:8765/design/index.html)。

体验模式进入“第七页 → 设置 → 连接手机”，创建连接。手机与电脑处于同一 Wi-Fi，扫码或打开屏幕中的局域网地址。HTTP 在 8766，HTTPS 在 8767；地址按当前电脑的局域网 IP 生成。服务和工作台需保持打开，主预览每两秒同步。同一标签页刷新保留手机连接；结束连接会撤销令牌，新配对结束旧配对。

手机设置包括留言、小纪念、钟面、秒数、亮度、音量、自动回主页、饮水目标、木鱼声音、目标星期、阅读内容、倒计时和颜色。留言和纪念独立保存，可填写纪念日期，正文留空后保存可清空对应便签；今日心情直接引用第五页记录，在设备日记中编辑。保存立即同步并持久化；后台刷新不覆盖有未保存修改的表单。

设备预览的“第七页 → 设置”也可直接调节亮度和音量，拖动立即生效并自动保存。已连接时与手机共用 `deviceSettings`，两端修改相互同步；手机上未保存的草稿仍保留。亮度为 10%～100%，音量为 0%～100%，0% 静音；当前 HTML 的音量应用于木鱼声音，屏幕亮度通过显示滤镜模拟。

## 定位与天气

手机直接输入中文城市名并点击“保存天气城市”，例如杭州、北京、昆明。服务使用 `https://uapis.cn/api/v1/misc/weather`，开启扩展气象字段与最多七天预报；主页与天气页共用同一城市。显示接口返回的空气质量指数和类别，不套用美国 AQI。保存后每十分钟刷新，不要求手机始终打开；更新失败保留已有读数。

电脑预览的“使用手机定位或坐标”中保留 GPS 和坐标入口，先通过 Nominatim 反查城市再请求 UApi。反查失败提示输入城市。

GPS 需要可信 HTTPS：

1. 从手机页下载本地信任证书。
2. 在手机安装并信任该证书。iOS 通常先安装描述文件，再在“关于本机 → 证书信任设置”开启完全信任；Android 在系统安全设置安装 CA，浏览器支持因系统而异。
3. 从手机页打开 HTTPS 定位入口，授权位置后点“获取手机定位”。
4. 无法建立可信 HTTPS 时，直接输入中文城市名称并保存。

脚本不会安装电脑或手机的信任设置。电脑 IP 变化后运行 `./design/start_phone_service.ps1 -Restart`，更新包含新 IP 的服务证书；若提示创建新根证书，需在手机重新下载并信任。证书和私钥在 `design/.local/`，不进入导出。浏览器授权流程与坐标同步已自动验证，真实手机 GPS 和证书信任尚未实物验证。

## 接口

| 接口 | 用途 |
|---|---|
| POST /api/pair | 工作台本机配对 |
| GET /api/phone-state | 手机心跳和读取配置 |
| GET /api/device-state?since=revision | 预览增量读取 |
| POST /api/phone-save | 手机保存 patch |
| POST /api/device-sync | 桌面同步，revision 冲突返回 409 |
| POST /api/location | 直接传 city；兼容 latitude / longitude 反查城市 |
| POST /api/weather-refresh | 刷新已有位置 |
| GET /api/search?city= | 搜索城市 |
| GET /api/qr | 配对二维码 |
| POST /api/disconnect | 结束连接 |
| GET /trust.cer | 本地根证书 |

连接令牌有效期 12 小时，不进入 JSON / HTML，也不写日志。设置、位置与日志保存在 `design/.local/`。

## ESP32

电脑服务用于 HTML 预览；开发板运行独立的自包含手机配置页。设备“设置 → 连接手机”显示热点名、Wi-Fi 密码与连接热点的二维码，手机连接后由通配 DNS 和系统网络探测重定向引导打开配置页，无需网页登录。若未弹页，打开 `http://192.168.4.1/`。热点连接仍需 Wi-Fi 密码。

开发板已有七页 LVGL 桌面、钟面、2.4 GHz Wi-Fi 配网和共享设置。热点页 `/api/location` 接收 `{ "city": "杭州" }`，保存城市到 NVS，联网后请求 UApi 天气。`/api/gift` 读取共享配置并保存手机留言等设置；旧 `/api/message-content` 保留兼容。手机留言存储在设备，重启保留；轮询和保存响应保护未保存的草稿。

2026-10-11，桌面、小智 2.5.0 与配套资源已完整烧录到 COM8，开发板自检、七页画面与像素钟秒数刷新检查通过，原有触摸校准及亮度、音量保留。源码也通过主机交互、天气解析和 LVGL 集成验证。设备目前未连接可上网的 Wi-Fi，联网后会自动校时并更新天气；热点自动弹页仍需实体手机验收，手机系统未弹页时可使用上述手动地址。实板记录见 `hardware/全部固件烧录验证.md`。
