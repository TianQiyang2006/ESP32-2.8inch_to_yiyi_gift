## UI 设计阶段

- 用户选择清爽森林风格：浅色背景、绿色点缀、小黑陪伴。
- 时间/天气等信息优先保证可读，主题素材作为配色与陪伴元素。
- 原型按 320×240 逻辑像素设计；电脑显示的物理尺寸不等于真实屏幕。
- 原型右侧提供页面快速入口，以及随页面更新的交互、实现条件和待验证说明。
- 原型默认启用设计模式，暂停闲置返回，便于讨论 UI；关闭后恢复 60 秒闲置返回。
- 设计模式只属于浏览器设计工具，不要求成为礼物固件功能。
- 后续每次新增想法，先明确可行性、依赖与资源成本，再改原型；硬件资料到位后实现。
- 罗小黑正式角色/背景素材待参考图；当前用代码绘制占位，不代表最终美术。

## 产品与页面

- 罗小黑战记的小黑黑猫主题生日礼物；100 元以内；乐高外壳。
- 已购买 ESP32-S3、2.8 英寸 240×320 电容触摸屏板；桌面 USB 插线供电。
- 开机第一页：小黑、时间、日期和天气摘要。
- 第二页：暂定相册，仍可调整。
- 第三页：罗小黑主题留言，用户可选择主题和展示内容。
- 第四页：小黑主题的自定义倒计时。
- 第五页：相册、留言、天气、小智、日历、设置，共六个应用。
- 右滑 1→2→3→4→5→1；左滑 1→5→4→3→2→1。
- 暂定横屏 320×240；一级页面直接滑动，点图标进入应用。
- 小智语音唤醒进入原有对话流程；退出后暂定恢复页面、应用子页、照片和轮播状态。
- 普通页面闲置 60 秒回主页，对话期间暂停闲置返回及相册轮播。
- 应用内有返回按钮，子页先返回父页，再返回全部应用。
- 第二页横滑切换一级页面，照片用按钮切换；相册应用内横滑翻照片，避免手势冲突。
- 长留言和设置列表支持上下滚动。

## 相册

- 读取 TF 卡 /photos/，第一版优先标准 JPEG，提前缩放到屏幕所需大小。
- PNG 等格式的实板支持以最终解码器为准；浏览器预览支持 JPEG/PNG。
- 文件名自然排序，例如 002 排在 010 前；索引只保存路径和必要元数据。
- 当前照片按需读取，不同时解码所有照片；是否预取取决于 PSRAM。
- 上一张、下一张、循环翻页、轮播（暂定每 5 秒）、手动重新扫描。
- 刷新后尽量保留当前文件，文件被移除时回到第一张。
- 竖图默认保持比例留边显示；裁剪填满作为后续选项。
- 无卡、空目录、卡错误和坏图片有明确提示，不阻塞界面和语音。
- 拔卡停止读取及轮播；解码失败允许跳到其他照片。
- 管理第一版为浏览、索引、轮播和刷新；删除/重命名不列为必做。

## 留言应用与第三页

- 应用负责选主题、选留言、刷新；第三页展示应用后的内容。
- 暂设森林小黑、小黑信笺、月夜小黑三种主题。
- 使用罗小黑形象与场景元素；正式素材待用户提供参考后生成和适配。
- 使用普通清晰的中文无衬线字体；文字、角色和背景分层绘制。
- 从 /messages/messages.json 读取 UTF-8 文本，点击刷新重新读取。
- JSON 为数组；每条有唯一 id、title、text，以及可选 signature。
- 用户点击“应用到第三页”后更新主题与内容。
- 实板在 NVS 等配置中保存 theme_id、message_id，避免只记数组位置。
- 解析和校验成功后才替换列表；错误保留旧内容。
- 选中留言被删除时选择第一条；空列表显示空状态。
- 已载入的留言在拔卡后仍可显示；刷新提示未插卡。
- 长正文自动换行并滚动，图片生成不包含正文。
- 动态中文需要字库覆盖：仅裁固定文案会缺少新留言中的汉字。依据内存和界面框架选择常用完整字库、TF 字体或同步字形方案。

## 天气

- 主页摘要；详细页显示地区、状态、温度、体感、湿度、风、最低/最高温。
- 预报、次要信息可滚动，按 320×240 适配；缺失字段用占位，不能编造数据。
- 图标统一尺寸与风格，覆盖晴、多云、阴、雨、雪、日夜状态与未知状态。
- 用户提供视觉参考，之后使用图片生成能力准备素材。
- 天气后台低频更新，建议 20～30 分钟；手动刷新节流。
- 显示真实更新时间；失败保留缓存并标记过期，首次无数据有提示。
- 天气 API、额度、密钥及是否使用代理尚未确定。

### 设置地区与手机位置

- 手机主动获取位置 → 用户授权 → 查询城市/区县 → 用户确认 → 保存天气位置 ID。
- 只需配置时定位一次；不持续跟踪手机。
- 手机定位可能综合 GPS、Wi-Fi 和基站，不保证一定来自 GPS。
- 定位失败或拒绝权限时允许手动输入/搜索城市、区县。
- 手动城市也需要天气服务的地区查询接口解析，不直接把文字当坐标。
- 普通局域网 HTTP/设备热点页通常不满足浏览器定位的安全上下文要求。
- 需要 HTTPS 手机页或手机端配合；如何把地区传给设备待通信方案确定。
- 不能承诺连接设备热点后就能直接自动获取 GPS。
- 地区保存到设备，重启继续使用；换地区后更新天气。

## 日历与倒计时

- 日历应用展示公历月历，周一为每周第一列，可切换月份、回到今天、选择日期。
- 今日、选中日和倒计时目标日有不同标记；不依赖天气服务。
- 第一版支持 1900～2099 年公历；正确处理闰年和跨年。
- 从日历选日期后进入倒计时编辑，也能从第四页直接进入编辑。
- 自定义名称和目标日期时间，明确按北京时间解释，不受手机/电脑浏览器时区影响。
- 名称使用普通中文字体，最长 40 字；长名称在展示页省略，在编辑页查看。
- 第一版保留一个目标；应用后第四页显示名称、剩余天数、时分秒和目标时间。
- 到期或选择已过去的日期时显示“已到达”，不显示负数、不自动转到下一年。
- 支持清除和重新设置；生日每年重复、多个目标暂不列为必做。
- 实板将目标名称、时间与时区保存到 NVS 等配置；断电重启保持设置。
- 实板尚未校时且无法确定当前时间时，提示联网校时，不显示错误倒计时。
- 输入长名称/日期在实板上采用选择器和手机配置；当前浏览器输入只是操作预览。
- 语音打断编辑时保留未应用草稿，退出后恢复编辑；应用前不替换原倒计时。
- 当前原型的设置仅在本次页面运行中保存，刷新浏览器后恢复初始空状态。

## 设置

| 项目 | 范围 |
|---|---|
| 亮度 | 背光滑块，最低值保留可操作亮度；夜间策略待定 |
| Wi-Fi | 状态、信号、网络名；手机配网、更换网络、自动重连 |
| 连接手机 | 配置页面地址/二维码；首次配网与日常配置分开 |
| 音量 | 小智播放音量，0 静音；不等同麦克风增益 |
| TF 状态 | 插卡状态、文件系统总容量、已用与剩余；只做信息显示 |
| 关于 | 项目/固件版本、开发板、Flash、PSRAM、屏幕、触摸及小智信息 |
| 蓝牙 | 用户尚未确定用途；原型先保留说明，后续可隐藏 |

- S3 支持 BLE，不支持经典蓝牙 BR/EDR，不能默认做普通 A2DP 蓝牙音箱。
- 蓝牙可评估配网/控制，必须先确认对应小智版本支持情况。
- Wi-Fi 配网优先沿用小智已有实现。
- 调节设置延迟合并或确认后写入，避免每次滑块移动都写 Flash。
- 连接手机暂不包含远程互联网访问、上传照片和同步留言，需另定范围。

## 素材和资源

- 全部应用优先静态罗小黑背景，提供纯白后备模式。
- 320×240 RGB565 全屏缓冲约 150KiB；是否常驻取决于 PSRAM 和音频缓冲。
- 预缩放图片、按需读取，第一版不使用全屏高帧率背景动画。
- 角色、天气图标、背景和文字分层，加载失败回到纯色。
- 真实屏幕需验证字号、对比度、触摸区尺寸与刷新效果。
- 当前主题是代码绘制占位图，正式图片尚未生成。

## 实板待确认

- Flash/PSRAM 实际容量；16MB Flash 不代表存在 PSRAM。
- 屏幕、触摸、TF、麦克风、音频、背光的驱动和引脚。
- 对应厂家示例、小智板型及源码版本、原厂固件备份/恢复方法。
- 音频与显示/TF 是否共享总线，以及联合工作性能。
- 生日日期、美术参考、地区、照片数量、第二页及返回规则最终选择。
