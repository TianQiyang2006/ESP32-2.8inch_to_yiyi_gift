## 看点详述

**01 · Crafloq クロックパレット｜サイバーパンクセット** — 最贴近「桌面钟主题化」的一条。它是 OBS 直播用桌面时钟/计时器（Windows）的**额外主题包（200 日元，10 套）**，主题命名本身就是一份风格清单：`Neon Alley`（青+洋红霓虹）、`Hacker Terminal`（绿终端）、`Chrome Edge`（冷铬）、`Night Tokyo`（粉夜景）、`Combat HUD`（琥珀仪表）、`Hologram`（半透明全息）、`Glitch Signal`（信号错位）、`Synthwave`、`Black Ice`（克制的冰蓝）、`Cyber Cat`（用猫的轮廓做赛博显示）。支持时钟 / 倒计时 / 正计时三模式；颜色、字号、装饰可改；部分主题带动效（默认关闭）；背景不透明度可到 0%（透明输出）。**看点：把「赛博朋克」拆成 10 个可切换主题，而不是做一套皮肤**——这正是我们「钟面」模型该有的粒度；`Cyber Cat` 还证明「猫 + 赛博」成立。

**02 · CodePen 霓虹数字钟** — 读到完整 CSS：时 / 分 / 秒三块独立卡片，每块下方一个极小英文标签（Hours / Minutes / Seconds），底部一行日期；数字用 Orbitron，`#00FF9F` 荧光薄荷绿，标签 `#4EB8DD`，背景 `linear-gradient(45deg,#1a1a2e,#16213e)`，面板是白色 10% 填充 + 1px 白描边 + `backdrop-filter: blur(10px)`。**看点：三块卡片 + 极小标签的信息分层，几乎是 320×240 的最优解**；玻璃模糊在嵌入式上做不了，换成 1px 描边 + 8% 白填充即可。

**03 · CodePen 赛博故障字** — 完整读到实现：两层 `::before/::after` 文字副本，洋红 `#E0287D` 偏左上、青 `#1BC7FB` 偏右下，叠 `step-end` 硬切关键帧、局部 `clip-path` 切片、`drop-shadow` 与 blur/字重跳变。**看点：RGB 三明治色差只要"两层偏移副本 + 硬切"，可整段翻译成 150–300ms 的瞬时闪**；常驻则开销 ×3 且中文必糊。

**04 · FreeFrontend 霓虹立体七段钟** — 仅搜索标题（2026-03-02 收录），页面因跨域重定向循环取不到正文。**仅作同类补充，不作依据**。

**05 · 赛博朋克 UI 组件库** — 43 个组件、`cy-` 前缀，主题即「切角边框 + 霓虹辉光 + 扫描线」。可直接借用的语汇：切角按钮（`--exec / --danger / --ghost`）、**四角括号面板** `cy-bracket tl/tr/bl/br`、环形 SVG 计量表（`stroke-dashoffset` 控制百分比）、六边形头像、`ID://0xF3A9` 编号、`// CONTRACT` 代码副标、`cy-hud` 顶栏。**看点：它是把 HUD 拆成"标准件"的清单，小屏只需保留三件——切角面板 + 四角括号 + 一行代码副标**，其余全删。

**06 · 《赛博朋克 2077》UI 拆解** — 三条可直接当纪律：① 调色板是**互补霓虹色并置**，会制造「色彩颤动」（盯红字会膨胀发虚，莫奈/梵高到 60 年代迷幻海报同源）；② 游戏还给字加荧光，**进一步降低可读性**；③ 剧情 UI（diegetic）很酷但信息排版失控、玩家找不到重点。作者结论是「风格化 vs 易用性」必须取舍。**看点：这是最好的反向教材——小屏要反着做：少荧光、少满屏字、少装饰。**

**07 · Pikka 霓虹配色 10 组** — 每组 4 个 hex，其中「Neon Tokyo Night Grid」= `#00F0FF / #FF003C / #FCEE0A / #05050A`，「Cyberpunk 2077 Night City Skyline」= `#FFE600 / #00E5FF / #FF1744 / #15161E`。并立 4 条工程规矩：多层 shadow 才像灯管（单层显得平）、**别用纯黑 `#000`**（画布 `#05050A` / 卡片 `#0D0E15` / 描边 1px 霓虹发丝线）、**90% 暗底 + 10% 霓虹**、重辉光在移动端掉帧。**看点：给了可直接抄的色组和面积纪律，正好治小屏"发光过度"。**

**08 · StyleAtlas 赛博朋克词条** — 中文语境里少见的反套路条目：推荐 **55 / 30 / 15** 面积比（`#20B7C6` / `#DA3A91` / `#D9CF2F`）；明确「**青洋红不是必要配色**」，可以低调、工业灰、日光化；字体条目要求「多语种标识和代码必须准确或明确虚构，**不以随机亚洲文字制造异域未来**」；数字界面条目要求降低装饰密度、正文/按钮优先可读。**看点：唯一同时给出"比例"和"别做什么"的资料，适合当评审 checklist。**

**09 · THANKO Cyber punClock ghost** — 读到全部规格：6 支玻璃圆柱罩，每支内嵌一小块 LCD，LCD 背后有 RGB 背光灯；内置 **27 种数字样式**且支持上传自定义图；底座是能看见主板的亚克力「骨架」；200×70×65mm、USB 5V 1A、¥15,200、2022-11-30 发售（现售罄）。**看点：真机把"辉光管"拆成外框 / 屏内容 / 氛围光三层——我们的 2.8" 屏同样可以这样分层做，而不必真去模拟玻璃。**

**10 · Tokyoflash『Sliced』LED 表** — 在基本 7 段数码上，用**平行斜线切掉几段无用笔画**再重连，每位因此需要多于 7 颗 LED；上两位显示小时、下两位分钟；附 9:57→10:06 的动画 GIF。评论区一致挑「黑底黄字」版本，工作室评价「数字的分段与斜线是扎实的概念」。**看点：不牺牲识读的赛博改造——只给七段加"刀口"就够，比整屏 glitch 高级得多。**

**11 · Elecrow 复古未来混合钟** — 设计说明写明：**「秒是唯一一直在动的部分」，所以把秒交给 WS2812 灯效表演**，LCD 只负责安静的小时/分钟；硬件为 Pico 2 + 2× ST7789 + DS3231 + 3× WS2812，骨架 PCB 外露，自称 cyberpunk × steampunk 折中。**看点：一个明确的动效分配决策——把"动"集中在一个元素上，其余保持静止。**

**12 · A.S.M. Kobayashi《Electric Neon Clock》** — 2026-08-08 → 10-25 于 AGM 展出；混合纪录片 / 表演 / 装置的沉浸式作品，素材来自艺术家家族档案，围绕一只霓虹钟展开（页面正文在"family archives, which are…"处截断，故未取得更多细节与配色）。**看点：把霓虹钟当叙事装置而不是装饰——对"礼物"属性有直接启发：钟面可以承载私密记忆。**

**13 · Amazfit GTS「Cyberpunk 2077」表盘** — 2020-03-21 上传，41 人收藏，标签 `cyberpunk / neon / digital`，作者注明 "Made for fun, not official"。**看点：粉丝向表盘只要"数字 + 霓虹 + 作品符号"三件就成立**，说明小屏上符号比细节更重要。

# 二、反复出现的视觉母题（8 条）

> 每条：为什么像赛博朋克 → 在 320×240 / LVGL 8 上是否可行（只谈视觉与开销，不写代码）。

### 母题 1 · 霓虹七段数码 + 多层辉光
- **为什么成立**：七段是电子表 / 仪表的血统，霓虹是城市夜景的光源，两者叠加＝「家用科技被城市霓虹污染」。对应 02 的七段排版、09 的管状实物、10 的斜切七段。
- **小屏可行性：高。** 4 位数字每位约 56×80px，加冒号总宽约 250px，正好一行铺满 320；辉光**不要实时模糊**，用「同色描边 2–3 层 + 1 张预渲染径向渐变」即可（素材 ≤30KB），刷新只重绘秒位一小块。
- **注意**：辉光层数一多就在 2.8" IPS 上糊成一团白（06 批评的正是这个），层数 ≤3、透明度递减。

### 母题 2 · 扫描线 / CRT 荫罩
- **为什么成立**：CRT 是「高科技、低生活」里那个"低"的物证；08 把「旧基础设施、数字噪声」列为赛博朋克的材质基因。
- **小屏可行性：中。** 1px 线 + 2px 间隔＝80 条，会和 8–12px 中文小字打架；建议 **3–4px 节距、透明度 8–12%、只盖背景不盖数字**。整屏一张半透明 PNG 叠层约 100–200KB，静态无刷新开销。
- **注意**：叠层会整体压暗，夜间模式要能一键关掉。

### 母题 3 · RGB 色差 glitch / 切片错位
- **为什么成立**：信号故障＝系统不可信，是赛博朋克叙事的核心动作；06 的「色彩颤动」是它的静态版，03 是它的动态版。
- **小屏可行性：低（只能做瞬时）。** 文字要画 3 份（偏移 1–2px），开销 ×3；中文笔画密，错位 2px 就变糊字。建议**只在秒跳、切换钟面、整点**做 150–300ms 一次性闪。
- **注意**：只对数字 / 英文副标用，别对中文正文用。

### 母题 4 · HUD 圆环 + 刻度 + 四角括号 + 切角面板
- **为什么成立**：军事 / 仪表 HUD 带来「被系统监视」的压迫感；切角面板来自"工业外壳被削掉一块"的实体感；05 把这一整套做成了标准件。
- **小屏可行性：高（性价比最高）。** 1px 圆环 + 60 条 2px 刻度在 240 高内完全读得清；四角括号每角 12×12px 就够；切角 6–8px 用 3 段直线拼。几乎无刷新开销（只在秒弧变化时重绘一小段）。
- **注意**：环内放时间会立刻变"仪表盘"，环外必须留 ≥8px 安全边，否则顶到屏边显廉价。

### 母题 5 · 赛博城市天际线剪影
- **为什么成立**：08 说赛博朋克的空间由「基础设施与建筑层叠」组织；天际线是**最省像素的世界观暗示**——几根竖线就能说明"这是夜之城，不是卧室"。
- **小屏可行性：高。** 底部 40–56px 两层剪影 + 每层 20–40 个 1px 亮窗，3–4 色即可；纯静态几乎零开销，极慢平移（8–12px/s）也只重绘剪影带。
- **注意**：**不要放到文字后面**；只占底部一条，不参与信息区。

### 母题 6 · 故障警告条 / 伪造系统文案
- **为什么成立**：黄黑危险条纹是工业安全色，天然带"要出事"的压迫感；顶部一行 `WARNING // TEMPORAL DRIFT 0.00s` 就把钟变成了"事故现场监测仪"。
- **小屏可行性：高。** 14–18px 高的 45° 斜纹条（4px 周期平铺图约 2KB）+ 8px 等宽字，一行 ≤24 个半角字符。
- **注意**：08 明确反对「随机亚洲文字」；日文 / 伪代码要么写对、要么明确是虚构代号。

### 母题 7 · 洋红 / 青双色霓虹（以及 90/10 用色纪律）
- **为什么成立**：互补色并置产生「色彩颤动」，是赛博朋克最经济的识别符（06 / 07）；但 08 提醒它并非必需品，也可以是琥珀+绿（终端）、冰蓝（Black Ice）。
- **小屏可行性：高，但必须克制。** 主光只占**约 10% 面积**（数字 + 1 条线），其余 `#05060A` / `#0B0E14` 深底；第二色只做 1–2 个 4px 强调点（冒号、秒点、状态灯）。
- **注意**：IPS 背光会让纯黑发灰，**深蓝黑比 `#000000` 更像"黑"**；大面积高饱和洋红夜间刺眼，夜间模式降到 40% 亮度或换琥珀。

### 母题 8 · 等宽 / 科技几何字体 + 小号编码文案
- **为什么成立**：等宽＝终端与代码，几何无衬线（02 用的 Orbitron）＝航天仪表；小号编码文案制造"信息过载但有等级"的 HUD 感（05 的 `// CONTRACT`、`ID://0xF3A9`）。
- **小屏可行性：高。** 大数字用七段自绘或 DSEG7（硬边比抗锯齿更好看）；辅助信息 8px 像素等宽；**中文不低于 12px**，沿用现有字库，不新增全量 CJK。
- **注意**：中英混排行高至少 1.3 倍，否则中文会被等宽英文的紧凑节奏带糊。

# 三、320×240 上最可能出效果的两个方向

> 与同日期目录 `design/cyberpunk-clock-research-20261115/mockups/` 里已存在的三个方向稿（`face-01-neon-seven` / `face-02-holo-hud` / `face-03-glitch-terminal`，另有 `faces-contact-sheet.png`）对照：下面 **A ≈ 01**，**B ≈ 02**，03 作为低成本备选。

## 方向 A · 霓虹七段 + 城市剪影（推荐度最高）

**版面（320×240）**
```
┌────────────────────────────────────────┐ 0
│ YIYI_DESKTOP // CLOCK-07      ● SIG   │ 16px 状态条（8px 等宽）
│                                        │
│   ██  ██   :   ██  ██                  │ 七段数字 高 88–96px
│   ██  ██       ██  ██                  │ 单色主光（青），冒号第二色（洋红）
│                                        │
│ 2026.11.15  星期六          SYS_NORMAL │ 12px
│ ▁▂▃ 城市剪影（两层 + 1px 亮窗）   ▃▂▁   │ 44px
└────────────────────────────────────────┘ 240
```
**为什么最容易出效果**
- 七段是代码可画、可缩放的形状，**不需要位图字库**，也不受中文抗锯齿影响；
- 单色主光 + 深底＝对比度天然够，2.8" IPS 在室内弱光最好看；
- 信息只有「时间 / 日期 / 状态」三层，符合 06 的反面教训（少荧光、少满屏字）；
- 剪影只占底部一条，不抢数字。

**动效预算**：冒号 1Hz 闪烁；每 10 秒一次 120ms 的 1px 色差闪（母题 3 的克制版）；剪影每 30 秒平移 2px。总重绘面积 <20%/秒。

**风险**：满屏辉光会糊；洋红面积务必 ≤5%。

## 方向 B · 全息 HUD 环 + 大号时间（最"耐看"）

**版面（320×240）**
```
┌────────────────────────────────────────┐
│ HOLO // LOCAL TIME          MODE 07    │ 16px
│         ╭───────────────╮              │
│      ╭──┤   23 : 47     ├──╮           │ 圆环 r≈92，60 刻度 + 4 主刻度
│      │  ╰───────────────╯  │           │ 时间 64–72px 几何无衬线
│      ╰──── 秒弧（6°/s）────╯           │
│  2026.11.15   23.5°C   52%   USB       │ 12px 三小格
└────────────────────────────────────────┘
```
**为什么耐看**
- 细线 + 刻度的信息密度低，长时间看不累，更接近"陪伴型桌面摆件"而非"游戏 HUD"；
- 秒用**弧长**表达（每分钟一圈），比跳数字安静——对应 11 号项目「秒＝表演层」的思路；
- 与现有森林主界面冲突最小，适合作为「第 4 种钟面」而不是整套皮肤。

**动效预算**：秒弧每秒重绘 1 小段（约 6°）；切页时环扫描一圈 600ms；刻度不动。

**风险**：1px 细线在 2.8" 上可能发虚——需整数坐标、关抗锯齿或改 2px 线；中文小字 ≥12px。

## 备选 · 故障终端（绿 CRT）
与 01 号主题包的 `Hacker Terminal` 同源：**绿字 + 扫描线 + 底部警告条**，实现最便宜（几乎全是文字与 1px 线），但"礼物感"偏冷，建议只做彩蛋或夜间模式。
