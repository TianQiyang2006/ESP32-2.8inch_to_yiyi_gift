# 小黑桌面 HTML 设计工作台

实时预览：[打开设计工作台](http://127.0.0.1:8765/design/index.html)。

## 页面与应用

七页依次为主页、天气、放假倒计时、名言与诗句、心情与日常、留言、全部应用。相册与照片上传已移除；导入旧配置保留留言、倒计时、日常记录和应用网格布局，清除旧照片。主页插画只作展示。

第六页为浅黄色小黑背景的留言板，直接显示大面积留言正文；点击“阅读全文”进入详情，“手机编辑”进入“设置 → 连接手机”。第七页包含时钟模式、留言、天气、小智、日历、设置。设置内可直接调节屏幕亮度（10%～100%）与音量（0%～100%，0% 静音），并保留 Wi-Fi 配网与连接手机两个入口。调节立即生效、自动保存，连接手机后双向同步；亮度在 HTML 中模拟显示效果，音量控制木鱼声音。桌面无通用顶部标题和装饰色条，电池背景透明。

## 第六页留言板

使用用户提供的浅黄色小黑插画，原图存档为 `assets/message-board-yellow-source.png`。`prepare_message_yellow.py` 去掉截图的黑色外边框，按原始比例缩放并延展上方纯色留白，生成 960×720 背景 `assets/message-board-yellow.png`。页面将插画作为浅色水印，突出大面积正文。

页面仅保留“留言板”标题、手机编辑、留言标题/正文/落款以及全文入口；已移除三个分类标签和标题下寄语。留言区域为 288×178，占屏幕约 67%，正文字号默认 19px。正文直接滚动，不再只显示三行摘要；标题、长正文和落款均可阅读。全文详情支持 Esc 返回，返回后恢复主页面原阅读位置和焦点。进入手机设置后返回、修改无关外观设置，也保留未变内容的滚动位置。

留言继续读取 `letter`，手机和工作台编辑后同步更新。空正文显示编辑引导。其他页面的心情记录及已保存的纪念数据继续保存在配置中。

工作台支持四个图层：背景、标题、留言正文、手机编辑。旧版自动迁移到 `yellow-paper-v3` 的大面积文字布局，保留已有内容和其他页面布局。JSON / 独立 HTML 保留原有数据，独立 HTML 内嵌背景。

文件为 `message-board.js / .css` 和 `prepare_message_yellow.py`；更换原图后先运行 `python design/prepare_message_yellow.py`，修改后运行 `python design/build_designer.py`。验证入口为 `node tools/design-review/check-message-board.cjs`，覆盖移除分类/寄语、正文尺寸、旧布局迁移、滚动/返回、文本转义与离线导出。

## 手机设置

运行 `./design/start_phone_service.ps1`，在体验模式进入“第七页 → 设置 → 连接手机 → 创建手机连接”。手机与电脑接入同一局域网后扫码。

手机可修改留言、时钟预设、亮度与音量、饮水目标与木鱼声音、目标星期、阅读内容、倒计时和颜色。服务同步到工作台、缩略图和自动保存配置。直接输入中文城市并保存后，统一查询 UApi 详细天气；主页与第二页引用同一份数据，不固定默认城市。

局域网 HTTP 可修改参数和保存中文城市；折叠入口的 GPS 需要可信 HTTPS 与定位授权。服务提供证书下载与 HTTPS 入口，需在手机信任证书。详细步骤与硬件边界见 [手机连接说明](D:/Tian/给依依的礼物/design/手机连接说明.md)。

## 时钟模式

三种预设为时光山水、蓝色像素、白色翻页。蓝色像素按上传参考图显示四位时分与两点冒号，使用从参考图提取的发光方块构成 3×5 点阵，下方以同样点阵显示小号秒数，每秒更新，不显示月亮或日期。时光山水从 `Ui设计图片/时钟功能预设` 裁切背景，原图保持不变；时钟数字、日期、星期和可选秒数实时绘制。

| 北京时间 | 背景 |
|---|---|
| 00:00–05:59 | 凌晨 |
| 06:00–10:59 | 早晨 |
| 11:00–15:59 | 白天 |
| 16:00–17:59 | 日落 |
| 18:00–20:59 | 傍晚 |
| 21:00–23:59 | 夜晚 |

进入钟面后保持时钟模式，点左上角退出。预设也可在手机选择。后两种数字使用 SVG 和 HTML/CSS；背景中不含固定时间。重新裁切运行 `python design/prepare_clock_assets.py`。像素钟素材可单独运行 `python design/prepare_pixel_clock.py`；原始上传图片存档在 `design/assets/clock-pixel-reference.jpg`。

## 设计与导出

- 设计模式可选择、拖动、隐藏图层；体验模式可点击与滑动。右侧调整外观、预览内容及尺寸、位置、字号、透明度。
- 自动保存；Ctrl+Z 撤销，Ctrl+Shift+Z 重做，选中图层后方向键移动 1 像素。恢复设计保留日常记录和接口缓存。
- JSON 可重新导入；独立 HTML 内嵌所选素材和七页交互；PNG 导出当前 320×240 画面。时钟也能导出。连接令牌、Wi-Fi 密码不进入设计导出。
- 十个 GIF 保留 `罗小黑gif和表情/lv_0_*.gif` 原始字节与帧时长，只裁显示窗口，不重新编码。

## 共享数据与日常交互

所有时间、星期、月历和倒计时共用北京时间。关闭实时走时后可修改预览日期时间。日历停在今天时随跨月更新；手动浏览的日期保持选择。

天气使用 UApi，提供体感、高低温、湿度、风向风力、日出日落、气压、UV、能见度、接口空气质量指数及类别和最多七天预报；每十分钟统一刷新。缺失值显示占位，失败保留原读数和真实更新时间。电池 ≤20% 显示红色，未知充电状态不推算。

放假页默认周五“放假”，可设置目标星期及文字；当天 0 天，次日找下周。元旦和春节按民用日期计算，春节离线表见 `calendar-data-source.md`；每周目标不包含法定调休。

第四页一言使用 `https://uapis.cn/api/v1/saying`，读取根字段 `text`，接口没有提供作者时显示“作者未提供”。诗词使用 `https://poetry.palemoky.com/` 服务的随机接口 `https://poetry.palemoky.com/api/poems/random?lang=zh-Hans`。每日更新、独立缓存、失败保留、自定义文字和全文阅读均保留；旧的一言缓存会在下次自动更新时换成新接口内容，成功前保留原文。

一言服务允许 HTTP 页面跨域读取，但不允许 `file://` 的 `null` 来源。本地文件预览自动通过现有手机服务 `http://127.0.0.1:8766/api/reading/quote` 转发同一个 UApi 接口；运行 `./design/start_phone_service.ps1` 启动服务。通过本地 HTTP 工作台打开时直接请求 UApi，固件也直接请求 UApi。

第五页支持心情历史、编辑和删除；木鱼计数、声音和撤销；喝水快捷量、自定义量、明细与撤销。跨天切换当天记录，历史保留；跨午夜的日记草稿保留原日期。

## 维护与硬件边界

修改脚本、CSS 或素材后运行 `python design/build_designer.py`，更新离线导出包。模型为 `designer-model.js`，共享层为 `live-data.js`，手机服务为 `phone_server.py`，新设备交互为 `device-ui.js / .css`。历史 `prototype.html` 留作参考，当前工作台不提供相册。

Wi-Fi 浏览器列表标明交互预览。真实 ESP32 源码已有七页 LVGL 桌面、异步扫描、键盘输入、连接反馈、NVS 保存及手机留言接口。设备热点配置页支持中文城市、UApi 天气、免网页登录和系统网络探测引导。2026-10-11 已将包含像素钟秒数与手机配置功能的固件烧录到 COM8，设备自检、钟面打开和秒数刷新检查通过；当前未联网，热点自动弹页仍需实体手机验收。详见 [固件 README](D:/Tian/给依依的礼物/hardware/arduino/yiyi_desk/README.md) 和 [共享接口](D:/Tian/给依依的礼物/design/共享数据接入说明.md)。
