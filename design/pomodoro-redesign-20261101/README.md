# 番茄时钟重构方案 · 2026-11-01

状态：供用户审阅的设计重构稿，尚未接入运行固件或烧录。App 入口设计以及闹钟定稿保持不变。

## 原稿核查

原稿在 `hardware/arduino/yiyi_desk/src/pages/focus_page.cpp`。

- 暂停时把剩余毫秒保存到 `pomodoroElapsed`，继续时又用“总时长减去该变量”设置期限，混淆了已用和剩余时长。例如25分钟计时剩余17:42时，继续后会变成7:18，必须修正。
- 暂停状态仍可能显示“准备开始”，没有明确的暂停和继续提示。
- 只有单次专注与固定5分钟休息，没有周期轮次、长休息、明确的完成页面或完成记录。
- 改变专注时长、重置与阶段切换没有完整的状态规则；声音只有共用的木鱼短敲。

## 设计原则与页面

- 原生分辨率320×240；与闹钟定稿使用同样的米白背景、清楚的深色文字和圆角卡片。
- 专注采用暖橙色，休息采用绿色，并同时显示文字，不能只靠颜色区分状态。
- 倒计时48px，主要正文14–16px，主要按钮高40px以上。采用简洁进度条，留足时间数字的显示空间。
- 主页面显示：当前阶段、第几轮/总轮数、剩余时间、阶段进度，以及清楚的开始/暂停/继续入口。
- 计时中不把时长加减按钮放在主操作区。时长与轮次在独立设置页调整；提醒与自动衔接在第二页设置。
- 页面包含准备、专注中、暂停、专注完成待休息、休息中、时长设置、提醒与衔接、本组完成八种代表状态。
- 截图中的今日完成2个、50分钟以及17:42等都是演示数据，不写入设备统计。

## 一组番茄的流程

默认：专注1 → 短休 → 专注2 → 短休 → 专注3 → 短休 → 专注4 → 长休 → 本组完成。

完成第N轮专注，增加一个已完成番茄；只有前N-1轮进入短休，第N轮进入长休。休息不增加番茄数。

默认每个阶段结束后先显示“完成/待开始”页面，下一阶段的完整时长保持不动。开启自动衔接后，按对应开关自动进入下一阶段，以非阻塞提示替代强制停留的完成弹层。长休息结束后统一进入本组完成，不无限自动开启新一组。

## 开始、暂停、继续与结束

- 开始：设置单调计时期限，不通过界面每秒减1来计算时间。
- 暂停：保存准确的剩余毫秒。暂停期间不减少剩余时间、不增加实际专注时间。
- 继续：期限=当前单调时间+已保存的剩余时间。例如暂停在17:42，继续仍从17:42向下计时。
- 结束：先暂停并弹出确认；确认后结束当前会话，未完成轮不算一个完整番茄，之前已完成记录保留。取消时恢复弹框前的运行/暂停状态。
- 跳过休息：保留刚才已完成专注记录；进入下一轮准备状态，不自动把下一轮记为完成。跳过本组末尾长休则进入本组完成。
- 返回：回到桌面或桌面内其他页面继续计时，不弹结束确认，不改变当前阶段。回到番茄 App 时显示相同状态。
- 误触处理：结束需要二次确认；暂停和继续立即生效并避免连续点击造成状态错乱。

## 状态与计时正确性

主要状态为：准备、专注运行、专注暂停、专注完成待休息、休息运行、休息暂停、休息完成待专注、本组完成、重启后中断。

1. 使用64位单调计时，NTP校时、修改日期和跨午夜都不改变当前阶段的剩余时长；倒计时无需联网或已校时才能启动。
2. 背景任务目标每100ms检查到期。LVGL只负责展示，任何网络操作、页面切换或界面刷新都不作为唯一到期入口。
3. 使用会话ID与阶段ID去重，同一阶段只完成一次、提示一次、记账一次。
4. 剩余秒数向上取整显示，超过期限才到0；进度按实际已运行时间计算，暂停不推进。
5. 自动衔接使用原定阶段期限作为下一阶段的时间起点，不把调度延迟反复累积。如果出现异常长的调度中断，不跨越并虚构多个已完成专注，而是标记中断等待用户处理。
6. 普通熄屏不中断计时；不进入尚未验证定时唤醒的深睡眠路径。关机、掉电或切换独立小智固件时，不能承诺后台计时仍在运行。
7. 正常运行条件下的实板验收目标：到期后1秒内完成状态切换并发出可用的提示音。此目标尚未实板测量。

## 完成记录

- 主页面展示今日已完整完成的番茄数和这些完整番茄的专注分钟数，结束/重置/跳过不会把未完成轮充数。
- 本组完成页展示实际完成轮数和累计专注分钟数。若某轮参数锁定为25分钟，4轮完整完成对应100分钟；不是依赖写死的展示值。
- 保存完成事件与统计时需要幂等，重开页面、重复收到事件或重启不能重复累加。
- 未校时时仍能计时并保存未归日的完成记录；每日统计显示“日期待校准”，恢复可靠日期后按可追溯记录归日，不把全部历史硬算到当天。
- 日期跳变不会重置当前运行阶段；跨日统计与专注阶段本身分开处理。

## 与闹钟协同

闹钟提示优先级高于番茄提示和铃声试听。闹钟到点时番茄计时继续；若番茄阶段同时完成，只完成和记账一次，先保存完成提示，待闹钟处理后再展示，不叠加播放铃声。禁止覆盖或改动已定稿闹钟的独立音量、铃声与停止/贪睡规则。
