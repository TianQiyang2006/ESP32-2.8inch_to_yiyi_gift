# 在线 FM 界面 · 2026-11-14

本轮实现320×240横屏在线FM应用界面。使用现有LVGL8.4、现有Noto Sans SC与Montserrat字库，收音机机身、扬声器刻线、刻度、爱心和应用图标均为代码绘制，没有增加位图素材。

设计延续音乐应用的奶油色／鼠尾草绿／墨绿，加入琥珀色播放提示。收听页将台名、节目元数据与直播状态分层，底部提供上一台、播放／停止、下一台，音量和收藏放在两侧。网络电台不显示虚构的MHz频率，卡片右下角仅显示真实电台序号。

- 主收听页：选台、收藏、节目标题滚动、直播／连接／缓冲／停止状态。
- 电台列表：全部／收藏切换、可滚动列表、当前电台高亮、迷你播放器。
- 音量抽屉：0–100%、加减、静音／20／40快捷档。
- 空收藏、未联网、连接失败、设置保存失败均有明确反馈；错误提示可点击重试。
- 退出页面后清除控件引用，局部返回优先关闭音量或列表，再交回桌面导航。

[可点击界面预览](index.html)使用实际LVGL渲染截图，配合页面热点浏览。默认六台来自生产代码同一份电台表：北京音乐广播、动感101、经典947、广东音乐之声、中国之声、北京新闻广播。节目文字为状态演示；最终设备使用 `Icy-MetaData: 0` 默认不请求元数据，解析与显示能力保留，没有元数据时显示普通陪伴提示。预览播放状态由主机测试驱动，不连接音频，不替代真实电台播放验证。

## 最终固件验证

`0.19.0-online-fm` 完整构建及镜像一致性核验已通过。最终应用镜像为 7,946,448 B（7.578 MiB），现有 8.5 MiB 桌面分区还余 966,448 B（0.922 MiB）。核验覆盖 499 个源码／配置文件、373 个编译单元，并确认导出镜像与构建镜像相同、UI 源码与截图哈希一致、ESP32-S3 镜像校验有效。最终镜像 MD5 为 `8f5167ca63fef8c4311f1a787a32aee3`。

最终默认六台使用 HTTP 连续 MP3，HTTPS 能力保留。core 0 的网络接收与解码／PCM 输出使用两个后台任务；PSRAM 包含 64 KiB 网络环形缓冲和 64 KiB 线性输入，压缩缓冲共 128 KiB。首次蓄满 49,152 B 开始播放，短缺后重新蓄至 16,384 B 恢复，接收无数据超时为 15 秒。

详细记录见 `hardware/在线FM实现与验证-20261114.md`；核验报告在 `build/online-fm-20261114/firmware-verification.json`。

用户批准后已刷入最终镜像，并完成完整 app0 回读校验。刷入前完整备份为 `build/online-fm-20261114/deployment/before/full-16mb.bin`，最终校验日志为 `deployment/buffer-watchdog-delta.log`，部署汇总为 `deployment/deployment-verification.json`；此处 `deployment/` 相对于 `build/online-fm-20261114/`。

最终镜像上，北京音乐广播、动感101、经典947、北京新闻广播各通过约 15 秒吞吐检查，中国之声通过 60.081 秒解码输出检查（约 31,258 PCM 样本／秒）及停止后任务退出检查。中国之声报告保留启动阶段已有的 15 次累计解码错误，没有将其视为零错误。广东音乐之声发生缓冲，未通过吞吐要求，电台遍历报告整体为失败。实机证据分别在 `deployment/device/stations-20261114-121443/verification.json` 与 `deployment/device/soak-20261114-121839/verification.json`。这些有限时长检查不代表默认六台长期稳定或完全无卡顿，也不替代扬声器人工听感验收。

最终操作检查 `deployment/device/smoke-20261114-122153/verification.json` 通过打开不自动播放、播放、音量、收藏／列表、返回、后台播放与停止回收，并保留对应设备截图。`deployment/device/reminder-20261114-122229/verification.json` 通过真实 3 秒倒计时试听抢占／恢复检查，未保存计时器草稿。最终状态报告 `deployment/device/final-20261114-122318/verification.json` 确认原有无关设置保持，FM 已停止、任务退出，FM 音量保留 20%。
