# 原生 LVGL 设计渲染

这是独立的设计确认用渲染器，不是已接入正式固件的游戏实现。

运行：

```powershell
python design/game-refactor-20261112/native/render.py
```

脚本编译本目录的新布局代码，链接现有主机缓存中的真实 LVGL 8.4 与项目 Noto Sans SC 中文字体，在320×240、RGB565的软件显示设备中渲染。游戏规则由网页原型单独验证；此处的指针事件检查用于验证控件可点击且没有被其他控件遮挡。

输出位于相邻的 `screenshots` 目录；`overview.png` 为六张截图拼成的总览，其余每张均为320×240原生截图。主界面包括入口、跑酷、拼块、切水果、猜色密码，以及统一准备、暂停、重开确认、失败和胜利画面。`code-empty`、`code`、`code-full` 另外展示空输入、未填满和填满三种状态；前两种提交键禁用，只有填满才启用。

主控文字使用12/14/16px。10px仅用于非操作提示与历史序号。猜色盘和色板均有数字1–6，反馈使用“正位／同色”数量，避免只依赖色彩。

`verification.json` 记录实际字形覆盖、文字无裁切、屏幕边界、控件至少32px尺寸和真实LVGL指针分发计数。该检查不等于实板触摸手感、音频或帧率验收；本阶段没有打开串口或写入硬件。
