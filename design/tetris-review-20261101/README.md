# 俄罗斯方块设计预览

状态：待用户确认的提案。本轮只整理和生成预览，不编辑固件源文件、不连接开发板、不刷入。

- 分辨率：320×240 横屏，沿用奶油白底、深绿文字和浅绿按钮。
- 桌面入口：基于已部署0.7.2第二页，原闹钟和番茄钟不移动；俄罗斯方块新增在下一行左侧，图标56×56，14px透明白色文字，不加遮罩。每页仍不超过6个App。
- 游戏画面：采用工作区已有草稿的原生LVGL渲染，左侧10×16紧凑棋盘（方块16×15px），右侧得分、等级、消行数、下一个方块与操作键。
- 操作：左移、右移、旋转、下移、落底；暂停、继续、重新开始、返回。
- 规则提案：7种方块、落点虚影、消行计分和逐级加速；离开游戏自动暂停；最高分保存。默认无声音，不占用闹钟或番茄钟音量。
- 当前棋盘为适配小屏而减少行数的紧凑版；如果需要10×20经典比例，可在确认前改稿，方块和棋盘宽度会相应缩小。
