# App 界面与功能设定 · 2026-11-01

## 已确认的 App 入口设计

`launcher-approved.png` 是用户已确认的入口设计。每页最多 6 个 App；第一页保留时钟模式、课程表、天气、小智AI、日历、设置的原位置；第二页是独立的闹钟和番茄时钟。小智AI标题相对上版下移 5px。两页标题共用原生 LVGL 字体、字号和米白色，不加文字遮罩、底板或阴影。

后续实现应按这份设计匹配，不擅自改变入口布局。该目录留档的是已确认预览；本次没有烧录设备，也不表示入口分页已经接入固件。

## 两个详情页的状态

`alarm-ui.png` 和 `pomodoro-ui.png` 来自现有 LVGL 主机渲染，原始分辨率 320×240；`two-apps-ui-preview.png` 以最近邻放大展示。两个详情页作为草案供用户讨论，没有在本次擅自重设计。

| 项目 | 闹钟 | 番茄时钟 |
| --- | --- | --- |
| UI | 浅绿卡片，提醒时间、启停、星期重复、贪睡 | 浅黄卡片，倒计时、阶段状态、开始/暂停、重置、时长调整 |

| 调整 | -5 / +5 每次调整 5 分钟，跨日回绕 | 专注时长 5–60 分钟；专注+ / 专注- 每次 1 分钟，运行时禁止修改 |
| 操作设定 | 开启、关闭；响铃或贪睡时可停止本次提醒 | 开始、暂停、从剩余时长继续、重置回初始专注阶段 |
| 重复与流程 | 分别勾选星期日到星期六；同一提醒分钟只触发一次 | 到点发声，切换专注/休息阶段并等待手动开始，不自动循环启动 |
| 提醒 | 设备声音提示；贪睡 10 分钟，到期再次提醒 | 到点设备声音提示 |
| 保存 | 时间、重复星期、开关存入设备配置 | 专注时长存入设备配置；进行中的计时不做重启恢复 |

闹钟停止本次响铃不会关闭以后选定星期的重复提醒。贪睡只在响铃中或已有贪睡任务时有效。离开详情页、返回同一桌面固件的其他页面时继续检查闹钟及计时；关机、重启、切换到独立的官方小智固件不保证任务持续运行。

当前范围不含多组闹钟、逐分钟时间选择器、自定义铃声、番茄轮次统计、长休息和历史记录。后续扩展应先讨论确认。

## 正式实施前需要处理

- 让已确认的 6+2 入口设计与当前实际固件入口代码一致；当前预览不能视为已经完成分页接入。
- 当前番茄草稿的暂停继续路径把剩余量与已用量混用，正式实施时必须确保从剩余时间继续；这里的功能表描述目标行为，不将此路径视为已经验证完成。
- 专注暂停后的文案目前仍显示“准备开始”，应与明确的暂停/继续状态一致。闹钟首次校时和设备提醒交互仍需验证。
