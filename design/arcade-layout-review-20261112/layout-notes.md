# 游戏布局确认稿

此稿仅用于确认320×240横屏的游戏布局，未修改生产固件。背景采用简单底色。六张画面是布局示意，不是已经完成的LVGL截图。

## 共同规则

- 每款游戏按棋盘与操作方式排版；不强制共用左右分栏。
- 常驻信息只保留分数、步数、生命、轮次等当局必需内容。
- 返回先暂停；重开需要确认。规则、难度、人机/双人、音效、选关移入暂停菜单。
- 棋类占满屏幕高度，导航移到右侧。其他游戏使用32px顶栏；这类小屏的顶栏触控高度是明确的空间取舍。
- 手势游戏内取消“屏幕左边缘右滑立即返回”，由明确的返回按钮退出，避免与走棋/滑动合并冲突。
- 小格不必都承担精确点击：五子棋先选点后确认；推箱子用划动；动作游戏提供大按钮或独立拖动区。

原有俄罗斯方块是已确认的独立应用。本轮先审阅新增游戏的布局；是否一起调整俄罗斯方块由用户决定。

## 确认后实现的边界

1. 先接入确认过的布局，再复验手势路由、触控热区、暂停菜单和返回行为。
2. 蛇、迷宫、打砖块与接水果涉及场地比例变化，需要重验速度、碰撞和随机落点。
3. 实际字形、LVGL控件和硬件手感必须另行验证；此布局稿不能代替实机验收。
4. 存储空间分配在布局确认后重新核算，现阶段不增加插画、关卡或其他占用。
