## 交互和适配说明

这是已确认的布局及交互设计。播放、进度拖动、模式切换、音量调整、歌单切换等功能尚未通过本轮设计工作实现。进入小智前仍计划停止音乐并释放音频资源；桌面第二页采用本页“用户确认”中的新顺序，取代第一版音乐入口位于第二行左侧的提案。

常用播放按钮的图标尺寸与触控区域分开设置。播放列表的曲目行高 40，底部控制区高 40；歌词、进度、页头及音量快捷档位使用各自的紧凑点击区域。弹层打开时背景不接受点击，点击遮罩或关闭按钮退出。

歌词界面的“返回”回到播放器；歌单界面的“返回”及迷你播放器的歌曲区域回到播放器。切换深色歌词界面不改变当前曲目、时间或音量。

长歌名应限制为一行并滚动或省略；长歌词按当前行区域换行，避免覆盖控制区。没有歌词时显示“暂无歌词”；网络异常时保留曲目信息，提供重新连接操作。实际实现需要进行设备字体、文本裁切和音频缓冲适配。

封面是本稿绘制的原创占位图，歌词是原创占位文案，并非《晴天》的真实歌词。时长、排序及播放进度为示例。“酷狗我喜欢 131 首”和“依依歌单 3 首”沿用此前的导入记录，本轮未查询服务器或同步账号数据。正式内容由 VPS 返回。
