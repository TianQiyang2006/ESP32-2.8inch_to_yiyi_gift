## 交互提案

- 桌面第二页新增“音乐”，保留闹钟、番茄时钟、俄罗斯方块的现有位置。第一页保留“小智 AI”。
- 进入音乐首先显示播放器；歌单默认收起，点击底部歌单按钮才显示。
- 上一首、暂停/原位续播、下一首均用触屏操作；歌曲结束按当前模式自动续播。循环图标用于切换列表循环、单曲循环、随机播放。
- 音量默认 40；点击扬声器进入音量调节。图标周围应留足点击区域，正式实现时将主要操作的触控区域扩展到至少 40×40，避免重叠。
- 歌单页面点击顶部名称切换“酷狗我喜欢”和“依依歌单”；点击曲目开始播放，点击底部歌名返回播放器。
- 点击歌词进入大字歌词页，随播放时间滚动并高亮当前行；顶部返回键回到播放器。
- 音频、播放列表和歌词由现有 VPS 提供，设备通过网络流式播放，不要求把整首歌保存进设备。正式实现需要缓冲与断线恢复，当前稿不代表这些功能已经完成。
- 缺少歌词时显示“暂无歌词”，仍可控制播放；网络异常时显示“连接中”或“连接失败，请重试”，暂停状态不显示为正在播放。长歌名与长歌词需要裁切、滚动或换行适配。
- 计划将音乐与小智分离：进入小智前停止音乐并释放音频资源。小智回归官方语音功能；实际移植仍需保留本板硬件适配和返回桌面能力，不能把这份设计当作官方固件兼容性已验证。
