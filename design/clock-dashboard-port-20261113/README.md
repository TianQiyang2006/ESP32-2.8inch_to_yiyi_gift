结论：当前 ESP32-S3 小设备可以移植 teojs/clock-dashboard 的钟面视觉和核心数字动效。实现方式是在现有 Arduino / LVGL 8 桌面中增加原生 C++ 钟面，复用时间、天气、农历和页面管理。

现已实现三款原生 LVGL 钟面及其共用设置，并按320×240屏幕重新优化数字、冒号、日期、农历与天气排版。标准天气钟与纯时钟均支持时分／时分秒，紧凑看板保留时分，合计五种显示形态。本文保留上游行为核对和设计依据；实现、验证结果与适配差异见[Clock Dashboard时钟移植验证](../../hardware/ClockDashboard时钟移植验证-20261113.md)。实机帧率仍需设备测量。

## 核心效果与移植办法

| 效果 | 已核实的上游行为 | 原生实现 |
|---|---|---|
| 数字滚动 | 旧字上移、新字从下进入，只有值变化的数字滚动 | 每位一个裁剪窗口，绘制旧字与新字并同步移动 |
| 回弹 | 800ms，`cubic-bezier(0.18,0.18,0.43,1.34)` | 使用同曲线的自定义动画路径，保留超调与回落 |
| 错峰 | 显示秒时，从左到右延迟500/400/300/200/100/0ms；隐藏秒时700/600/500/400ms | 每位独立起始时间，进位时由右向左依次滚动 |
| 倾斜 | 普通版每位随机−6°到+6°，600ms线性变化 | 将裁剪后的数字画布旋转，缓存字形，避免每帧栅格化字体 |
| 角度刷新 | 有秒时所有数字每秒换角，无秒时每分钟换角 | 保持原触发节奏；有秒模式需单独验证持续刷新开销 |
| 秒显示切换 | 普通版点击时间切换秒，字号和布局过渡500ms | 复用触摸事件、调整数字尺寸和位置 |
| 天气小图标 | SVG内含动画，如太阳光芒45秒转一周 | 图层拆分后旋转/平移，或小尺寸透明帧动画 |
| 雨雪雷电 | 雨40–150粒子、雪30–100粒子，雷电含柔光与整屏闪光 | 减少粒子数量，柔光预渲染；最终按设备实测调整 |

普通版默认黑底白字，开启倾斜、隐藏秒；README 中的蓝色时间是自定义配色。紧凑版采用左时间、右日期天气布局，并明确关闭数字倾斜，只显示时分。

## 全部时钟样式的范围

用户进一步询问全部样式是否均可移植。按当前核对版本，上游共有两套时钟视图组件，加上普通视图的纯时钟模式，共三种显示形态；手机横竖屏预览是响应式布局，不是额外的独立钟面。

| 显示形态 | 对应上游实现 | 移植目标 |
|---|---|---|
| 天气大字钟 | `ClockWeatherView.vue` | 上日期/农历、中间圆润大字、下天气；保留滚动回弹和可选倾斜、秒显示 |
| 紧凑看板钟 | `ClockWeatherViewCompact.vue` | 左侧窄长数字、右侧日期/农历/天气；保留逐位滚动，按上游关闭倾斜且只显示时分 |
| 纯时钟 | 普通视图的 `clockOnlyMode` | 隐藏日期天气、放大时间，支持时分与时分秒，以及滚动回弹/可选倾斜 |

全部样式共用的外观设置可一起移植：

- 六种预设颜色：白`#ffffff`、蓝`#659FE8`、粉`#EF7993`、橙`#F2A666`、绿`#8CDB92`、青`#68CDD7`，以及自定义颜色。
- 普通/纯时钟的100–900共九档字重、0.1–1.0透明度、−0.18到−0.08em字距；紧凑版原代码使用固定500字重，不应用该字距设置。
- 12/24小时制、普通/纯时钟秒显示、普通/纯时钟倾斜开关、日期天气布局的农历与节日开关。
- 天气图标动画、下雨/下雪/雷电开关；纯时钟模式按上游不显示天气特效。

这些外观组合已由共用数字动画引擎和不同布局实现，无需为每一种颜色重新制作整套位图动画。设备端新增三个样式入口和共用设置页。数字蒙版为100,263字节；各钟面PSRAM缓冲约262–396KiB，分配失败时回退到静态可读时间。

## 当前设备条件

- LCDWiki ES3C28P，ESP32-S3 N16R8，16MiB Flash、8MiB PSRAM。
- ILI9341，横屏320×240，RGB565，当前构建40MHz SPI。
- Arduino ESP32 2.0.17，LVGL 8.4.0，TFT_eSPI 2.5.44。
- 现有白色翻页已实现数字栅格缓存、420ms上下半片变形、20ms定时器和变化数字局部重绘；新增钟面可沿用其分配、释放与页面生命周期模式。
- 当前已有 NTP 北京时间、天气缓存与 `gift_lunar` 农历算法，无需为钟面新增整套网络服务。

满屏RGB565为153,600字节，40MHz SPI只计像素数据的理论满屏上限约32.6帧/秒，实际还有CPU绘制、传输命令和PSRAM访问开销。局部数字滚动与轻微旋转可行；大面积粒子、实时模糊和多层透明合成是主要性能成本。最终流畅度需原生实现后测量，`status.animFps` 的flush回调次数不能直接视为完整动画帧率。

桌面app0容量8.5MiB。本轮版本为`0.17.0-dashboard-clocks`，最终固件占用及其源码校验记录在移植验证报告中；历史版本的余量不作为本轮结果。

## 320×240 排版建议

普通版采用上日期、中间大时间、下天气的层次。保留圆润大字、蓝色/白色配色和紧凑的视觉关系，按原生像素重排小字，并为冒号留独立间隔。完整网页等比例缩小后，部分底部参数仅约6–8px，因此实际实现采用可读字号重新排版。

- 顶部：日数、星期、年月与精简农历，辅助文字采用12–14px。
- 中部：大号时分，保留滚动、回弹、错峰与倾斜；点击可切换秒显示。
- 底部：天气图标、状况、温度，再放湿度或温度范围；更多数据可从现有天气页查看。
- 已新增“天气大字钟”“纯时钟”“紧凑看板”三个预设，接入现有钟面选择和边缘返回逻辑。

## 实现验收

1. 已实现布局、数字滚动、回弹、错峰、旋转与原生天气图标。
2. 已用真实LVGL主机渲染验证普通换秒、09:59:59进位、午夜、12小时制首位显隐、校时跳变与无效时间占位。
3. 已验证反复进入退出、动画中返回、内存分配失败回退，以及跨进程配置恢复与写入失败保护。
4. ESP32构建结果见移植验证报告。本轮未刷机；普通、有秒及雨雪模式的设备流畅度与物理触摸响应尚未实测。
