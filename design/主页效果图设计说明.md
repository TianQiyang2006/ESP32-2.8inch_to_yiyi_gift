# 主页效果图 v1

2026-10-06 已完成第一张 320×240 横屏静态视觉稿，配套原图、三倍像素预览、可编辑 SVG 和独立美术层，用于讨论成品屏幕的构图。
这版由本地绘图与字体排版合成；当前会话没有可调用的图片生成工具，没有调用图片生成 API。黑猫为小黑主题的手绘造型草稿，不是官方角色素材。后续可保留排版、替换用户选定的角色素材。

## 首张稿

- 画布：320×240 横屏；另外提供 3 倍最近邻放大图，便于讨论真实像素下的细节。
- 风格：清爽森林，浅米白底、森林绿信息、黑色小黑形象。
- 时间：左侧主要区域，Bahnschrift 66px 字体，其数字可见高度约 47px；示例 10:08。
- 日期：时间下方，微软雅黑 13px；示例 2026年10月6日、星期二。
- 小黑：右侧，采用尖耳、绿色眼睛、卷尾的黑猫造型；独立素材约 109×134px，具体形象后续可按参考图调整。
- 天气：底部一条信息区，晴天图标、晴、24°、最低/最高 18° / 26°；数值都是排版示例，不代表实际天气，不擅自指定地区。天气应用中再展示摄氏单位等详情。
- 顶部：麦克风就绪和 Wi-Fi 图标仅演示正常在线状态；固件中必须由实际状态驱动，离线/静音不能沿用正常图标。
- 页码：底部五个轻量指示点，第一项高亮。
- 不在屏幕内加入浏览器操作提示、实现说明、英文装饰标题或硬件参数。
- 不在首稿塞入全部应用入口、留言正文和多日天气，避免挤压时钟。
- 文字由排版工具单独绘制，避免将生成图片中的文字作为最终动态文字。
- 图片和字体在 320×240 的实际分辨率下检查；放大图不代表屏幕能显示更多细节。

## 美术制作方式

本版：本地手绘几何路径，使用字体单独排版，再输出真实分辨率 PNG。原图经过四倍超采样抗锯齿；讨论预览从原图做最近邻放大，避免把高清插画误当作实际屏幕细节。

方式一：用户选定一张小黑图片，保留角色形象，裁剪、排版并合成效果图。无需图片生成服务；需要适合裁切的清晰图，透明角色图更方便。

方式二：图片生成 API 生成角色与森林背景，再单独排版文字。需要用户明确选择 API 方式并在本地配置 OPENAI_API_KEY；API 调用可能产生费用。

尚未调用 API；本版独立绘制，未使用现有网页中的占位猫。角色美术仍待用户确认。

## 交互与固件对应

- 天气整条区域为点击入口：x=16、y=174、宽288、高44，进入天气详情。
- 其余区域保留一级页面滑动；底部五点仅为位置指示，不作为小尺寸触摸按钮。
- 右滑依次为主页、相册、留言、倒计时、全部应用；左滑反向循环。
- 语音唤醒时由小智状态机切入对话界面；本图只是待机主页，不包含语音状态设计。
- 时钟字体需要最终选择支持设备的字体与授权；电脑上的字体排版不等同已提供 LVGL 字库。
- 建议 LVGL 承载文字、天气图标和触摸事件；静态美术层预缩放，时钟按分钟更新，天气低频更新，不反复全屏重绘。

## 实板实现条件

- 主界面由静态美术底图、时间/日期文字、天气图标和数值分层组成。
- 角色先静态；眨眼等动画在实板内存和帧率测试后加入。
- 背景预缩放；RGB565 全屏约 150KiB，可按资源选择分块绘制或 PSRAM 缓冲。
- 需要 ILI9341V 屏幕与 FT6336G 触摸驱动、中文字体、联网校时、天气服务及对应小智板型源码。
- 官方资料已确认 N16R8，静态主页的资源量可控；小智、TF 解码和 UI 同时运行时的资源余量仍需实板测试。
- 横置后屏幕扫描方向与触摸坐标需要一并旋转，避免显示正常、触摸错位。
- 背景可放 Flash 或 TF；时钟、日期和天气为动态组件。无需为这个主页增购硬件。
