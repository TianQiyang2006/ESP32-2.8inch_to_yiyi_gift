状态：设计已确认，并于2026-11-11实现、验证及刷入COM8。当前桌面固件版本为 `0.10.1-timer-layout`。本目录保留原始设计稿；生产页面与部署证据见 `hardware/倒计时布局重构部署验证-20261111.md` 和 `build/timer-layout-20261111/`。

## 页面布局

- 主页面：顶部标题与「提示音」入口；其下为整行「设置倒计时」。常用计时器用2×2卡片展示刷牙、蒸蛋、面膜、午睡，四项在首屏全部可见。超过四项时在卡片区域滚动。保留「＋添加」与长按编辑。
- 设置倒计时：独立时／分／秒滚轮页，00～23小时、00～59分、00～59秒；当前值48px，邻值21px。底部「存为常用」与「开始倒计时」，返回箭头取消草稿。0秒时开始按钮禁用，范围沿用1秒～23:59:59。
- 计时中：显示所选常用项名称（自定义计时显示「自定义」）、大号剩余时间、总时长及进度。底部「重置」「暂停」。暂停后主操作变为「继续倒计时」。返回桌面继续计时；当前存在运行中计时时，再进应用直接显示当前状态。
- 提示音：从主页面右上角进入，复用经典滴滴、温柔钟声、渐快提醒，保留试听与独立音量，默认20%。设置取消不修改有效值，保存后生效。
- 到时提醒：显示结束时间与计时名称；提供「停止提醒」「再来一次」。静音时仍显示视觉提醒。提醒在任意桌面页面可见。

## 交互路径

| 入口 | 行为 |
| --- | --- |
| 设置倒计时 | 进入独立时长页，默认显示上次保存时长；开始后进入计时中。 |
| 常用卡片 | 点击直接以该卡片时长开始，减少进入后的操作；复用当前保存的提示音和音量。 |
| ＋添加 | 进入时长页；选好时长后「存为常用」，进入现有名称输入流程，成功保存后返回主页面，不自动开始。 |
| 存为常用 | 进入名称输入流程，保留当前时长草稿；取消回时长页，保存成功回主页面。 |
| 长按常用卡片 | 编辑名称或删除；删除保留确认步骤。 |
| 重置 | 先确认，确认后回主页面；取消保留原计时状态。 |
| 再来一次 | 停止当前提醒，以本次总时长重新计时；不改动其他闹钟和番茄时钟。 |

常用卡片直接开始已在正式固件实现。设计稿中的所有时间均为演示数据。
